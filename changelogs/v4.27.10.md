# [4.27.10] — 2026-08-27 — 思考/工具调用显示扁平化、显示思考开关、窗口模糊度

本次更新包含 2 项新增、1 项体验优化。全部为 ldmbot 本地改动。

### 新增

- **显示思考独立开关**
  - WebChat 聊天侧加号菜单和侧边栏设置菜单都可切换「显示思考」，关闭后后端不发送思考内容
  - 与流式输出开关同构的逐请求覆盖链路：前端 show_reasoning flag → SSE body / WebSocket payload / Open API → 后端 request_flags → internal.py 三个 run_agent 调用点和 result_decorate 非流式注入路径均优先读前端 flag，无 flag 时回退全局 display_reasoning_text 配置
  - i18n 新增 reasoning.showEnabled / showDisabled 提示文案

- **窗口模糊度滑块（壁纸设置）**
  - 外观壁纸设置新增「窗口模糊度」滑块（0-40px），控制弹窗和移动端临时侧边栏的 backdrop-filter blur + saturate(1.5) 强度
  - 防止窗口透明度导致下层文字与窗口内容混杂，41 以上自动切换纯白不透明模式（不用模糊）
  - wallpaperApplier.js 写入 CSS 变量 `--window-blur`，wallpaper.scss 中弹窗/侧边栏消费该变量，PersonaForm 等组件同步接入

### 体验优化

- **思考/工具调用显示扁平化**
  - 思考块和工具调用块拆成各自独立折叠块，不再嵌套在同一 thinking block 里
  - 思考块：脑图标 + 「思考了 x 次」→ 点击原地展开思考内容
  - 工具块：扳手图标 + 「使用了 x 次工具」→ 点击原地展开各工具调用详情
  - 同一轮多次工具调用合并显示在一个块里
  - 删除 ReasoningSidebar（右侧侧边栏）和 ReasoningTimeline（嵌套时间线）组件，所有内容原地展开
  - 三个消息列表组件（ChatMessageList / MessageList / StandaloneChat）统一按 block.kind 分发
  - ChatInput 流式开关图标从写死改为动态绑定
  - 后端 BotMessageAccumulator 新增思考耗时计时（thinking_duration），思考结束时写入 think part
  - SSE 消息保存事件（message_saved）现在携带完整 message_parts 和 refs，前端无需额外请求即可还原消息结构

### 说明

- 更新后请**手动重启**一次服务
- 若面板显示异常，可用顶栏「强制刷新面板」或浏览器 Ctrl+F5
