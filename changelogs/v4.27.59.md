# [4.27.59] — 2026-10-31 — WebUI 日志页导出/搜索/插件筛选、首屏 CDN 阻塞修复、会话搜索与排序、管理员身份开关

本版包含六组改动：**WebUI 日志页能力补齐**（日志来源标注 + 插件筛选 + 关键词搜索高亮 + 按时间范围导出并默认脱敏）；**WebUI 首屏 CDN 阻塞修复**（移除 index.html 里的 jsdelivr defer 脚本，语音库改按需加载，国内网络不再白屏转圈）；**对话管理页会话搜索与默认排序**（按会话 ID / 名称 / 群号搜会话，命中自动命名别名，列表默认最近活跃优先）；**WebUI 聊天管理员身份开关**（输入框加号菜单切换，显式身份优先于 admins_id 配置判定，默认配置清空）；**日志控制台重复显示与自动滚动修复**（指纹去重 + Last-Event-ID 断线补发 + wheel/touch 跟随重写）；**恢复 WebUI 手动安装 pip 库**（恢复官方实现，demo 模式保护保留）。

## 🚀 新功能

### 1. WebUI 日志页导出 / 搜索 / 插件筛选

- **日志来源标注**：core/plugin 来源与插件名随日志记录注入（enricher 统一处理，emit 侧 getattr 兜底防子 logger 传播路径缺字段），SSE 实时流与 `/logs/history` 历史接口自动透传。
- **关键词搜索**：控制台输入 250ms 防抖即时过滤，命中关键词高亮（HTML 转义后 amber 标记）。
- **插件筛选**：下拉选项从日志缓存派生并与插件显示名映射，首位固定「仅核心日志」；仅控制台页启用，插件安装弹窗 / 知识库等复用页面行为不变。
- **日志导出**：`GET /api/v1/logs/export`，按时间范围（快捷近 1h/12h/24h/3 天或自定义）导出文本文件；优先读文件日志全量历史，未开启文件日志时回退内存缓存并剥 ANSI。**默认脱敏**：配置文件敏感键、Bearer/Cookie/JWT/PEM 私钥等常见凭证格式替换为 `[REDACTED]`，关闭脱敏有红字警告；导出任务单实例互斥，响应后临时文件自动清理。
- 日志页布局优化：删提示行、日志区 flex 自动占满、修复浅色主题下搜索/筛选/全屏按钮对比度与隐形问题。

### 2. WebUI 聊天管理员身份开关

- 聊天输入框加号菜单新增「管理员身份」开关（默认开启，逐消息生效不持久化），开启时本次消息直接按管理员处理，关闭则按普通成员——**显式声明完全取代 admins_id 配置判定**（即使发送者在配置里也按 member）。
- 身份经 SSE 与 WebSocket 两条聊天路径透传（非 bool 一律归一为未指定），未指定时回落原 `admins_id` 逻辑，旧前端 / 第三方调用 / Open API / 非 WebChat 平台零影响。
- `admins_id` 默认值 `["ldm"]` → `[]`：全新安装不再需要预置登录用户名；既有配置文件的值不会被动。配置面板补 hint 说明。

### 3. 对话管理页会话搜索与默认排序

- 新增「搜索会话 ID 或名称」：匹配会话 ID、user_id（UHO，含群号）、标题与 UHO 别名表自动命名（SQL 子查询），**不再搜会话内容**，含义从「搜历史消息」收敛为「找会话本身」。
- 列表默认排序由创建时间倒序改为 **`updated_at` 倒序**，最近活跃的会话排在最前。
- 删除「机器人 ID」死下拉（选项数据源在本项目前后端均不存在，自出生起永远为空）；筛选区重排为 类型 → 搜索关键词 → 搜索会话。
- 修复清除按钮把输入置 null 导致 `.trim()` 抛错、列表进错误态的隐患（快照构造统一兜底，新旧搜索框同享）。

## 🛠️ 重构与修复

### 4. 日志控制台重复显示与自动滚动失效修复

- **重复显示**：去重改指纹 Set（规范化 time + level + data，O(1) 且与缓存同步增删）；SSE `onopen` 不再全量重拉历史；断线重连带 `Last-Event-ID` 请求头（polyfill 走 headers 而非 URL 参数，此前断点补发机制从未接通）。
- **后端补发闭环**：`stream_log_events` 改为**先注册队列再补发**（补发期间新日志不丢），水位线逐条推进、实时循环跳过 `<= watermark` 的已补发消息——补发与实时重叠段不再重复，单条脏数据不断流。
- **自动滚动重写**：滚轮上滚 / touchstart 立即暂停跟随（程序滚动不触发这两个事件，判定无竞态），滚回底部按位置自动恢复；删除被节流 + rAF 窗口竞态吞掉用户意图的旧机制。
- 三处复用（控制台页 / 插件安装弹窗 / 知识库）同一组件统一生效。

### 5. WebUI 首屏 CDN 阻塞修复与语音库按需加载

- 根因：`index.html` 以 `<script defer>` 同步引入 jsdelivr 的 ort.wasm 与 vad-web（defer 阻塞 `DOMContentLoaded`），CDN 不可达的网络环境下整页启动挂到连接超时，表现为长时间白屏转圈、侧边栏时有时无，网络恢复即自愈。
- 修复：移除两个 CDN script 标签，**首屏零第三方 CDN 依赖**；语音库改在首次点语音输入时按需动态加载（先 ort 后 vad-web，失败置空缓存允许重试），CDN 不可达只影响语音输入功能本身，页面其余功能零影响。
- 语音运行时 wasm 资源路径维持 CDN 不变。

### 6. 恢复 WebUI 手动安装 pip 库

- 「插件管理 → 安装 pip 库」此前被短路禁用（方法体直接返回提示不真正安装），恢复官方实现：`demo_mode` 保护保留，`package` 必填 + `mirror` 可选，失败记录完整 traceback 后抛错给前端展示。
- 请求路径与参数结构不变（`/api/update_pip`），前端无需改动；核心更新流程的 requirements 安装不受影响。
