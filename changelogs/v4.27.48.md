# [4.27.48] — 2026-10-15 — 会话指令与运行中 Agent 交互治理、禁更环境变量可视化

本版本围绕「Agent 运行中时指令该怎么表现」和「禁更状态可见性」展开：`/reset`、`/new`、`/switch` 在会话中有 Agent 正在运行时的行为按各自语义重新定形——`/reset` 强制停止并丢弃被停任务的写回，`/new` 与 `/switch` 运行中明确拒绝，状态清晰可预期；禁更环境变量启用时在启动日志与关于弹窗中显性提示。另应反馈把 `/about` 项目介绍页的英文副标题改为中文。

## ⭐ 体验优化（1项）

### 1. `/reset`、`/new`、`/switch` 在 Agent 运行中的行为重新定形，状态清晰可预期

#### 背景与核心改善

此前这三条指令在会话中有 Agent 正在运行时的表现各不相同，且都不符合直觉：

- Agent 运行中发 `/reset`，回复「清除聊天历史成功！」，但旧内容稍后整段回来了——旧任务靠每 0.5 秒轮询一次的停止信号才发现要停，停下后收尾路径把「旧历史 + 本轮已发送内容 + 停止标记」全量写回，而写回目标正是刚被清空的那个对话，时序上几乎必然后到，清空就这样被覆盖回去。
- Agent 运行中发 `/new` 或 `/switch`，指令立即成功，但旧任务在后台继续生成、继续分段发消息，直到自己跑完才罢休，用户毫无感知。

本版按三条指令各自的语义重新定形：`/reset` 既然清空上下文，当前上下文就不再需要——强制停止且写回一并丢弃；`/new`、`/switch` 保留当前上下文——运行中拒绝执行，把状态明确告诉用户，不在后台偷偷跑旧任务。

- **`/reset`：强制停止 + 清空**。改用 `/stop` 同款机制：软停运行中任务并立即打断活跃 runner（不等 0.5 秒轮询），同时给被停任务打丢弃标记；历史保存入口检查到该标记即丢弃本轮写回。清空逻辑本身不变（清历史、清群聊上下文、清 LTM）。
- **`/new`、`/switch`、`/groupnew`：运行中拒绝**。检测到会话有活跃任务（含事件已结束但 runner 还在收尾的半秒窗口）时，回复「⚠️ 当前会话有Agent正在运行，请等待结束或发送{第一个唤醒词}stop停止后重试」，不执行切换。无运行任务时行为与旧版一致。
- **`/groupnew` 检查目标群会话**而非管理员自己的会话：管理员那边在跑，不影响给别的群建新对话。

#### 使用方式

- 想丢弃当前上下文重来：直接发 `/reset`，运行中的 Agent 会立即停止，本轮内容不再写入。
- 想保留当前上下文（新建或切换对话）：Agent 运行中会收到提示，等待其结束，或发 `/stop` 停止后再执行 `/new`、`/switch`。

#### 注意事项

- 与 `/stop` 的分工：`/stop` 是「停止但保留已发送内容」（按已发送内容落库并追加英文停止标记）；`/reset` 是「上下文已不要，连写回一起丢」。
- 提示文案给用户两个选项（等待结束 / 发送 stop），不强制用户必须停止。
- 第三方 Agent（dify/coze 等）分支不变：那类 runner 不走本地落库路径，没有写回竞态，仍为停止 + 删会话标识。

## ✨ 新增（1项）

### 1. 禁更状态可视化：启动警告日志 + 关于弹窗黄字提示

#### 背景与核心改善

`LDMBOT_DISABLE_UPDATE`（v4.27.45 引入）启用后会在本次启动拒绝一切主程序更新与回滚，但此前它完全静默生效：配置了的实例只会在真的去点「更新」或执行回滚时才被拒，平时没有任何办法确认「这台机器现在处于禁更状态吗」。排障时容易走弯路——WebUI 更新按钮点了没反应，翻半天日志才想起是环境变量挡的。本版把这个状态显性化：

- **WebUI 就绪后打一次警告日志**。放在 WebUI 就绪横幅之后一眼可见；文案与 `/upldm`、更新服务、回滚被拒时的报错完全同源。未启用时不打任何日志。
- **关于弹窗常驻黄字提示**。顶栏菜单「关于」打开的弹窗在信息区与按钮区之间显示黄色警示图标 + 黄字：「注意：你已启用禁止更新环境变量（LDMBOT_DISABLE_UPDATE），本次启动拒绝一切主程序更新与回滚操作。」未启用时该节点完全不渲染，无占位无闪烁。

判定与全库其余三处（主更新入口、聊天指令、回滚）共用同一口径与真值集合，不会出现「日志说禁了、关于页说没禁」的分歧。新增字段对旧版 WebUI 双向兼容。

## 🎨 界面文案（1项）

### 1. `/about` 项目介绍页副标题改为中文

副标题从英文 "A project out of interests and loves ❤️" 改为「一个出于兴趣与热爱打造的项目 ❤️」。该页是顶栏 Logo 在非聊天页点击时跳转的纯项目介绍页，与关于弹窗（运行状态信息）分工不同，禁更提示只放弹窗一处即可覆盖。
