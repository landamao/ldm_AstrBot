# [4.26.39] — 2026-08-20 — ChatUI 面板透明度统一、自定义壁纸开关、自定义 Logo、指令冲突详情查看

基于 ldm v4.26.38 的版本。本次为 ChatUI 侧边栏与主聊天区统一面板透明度，外观设置新增「启用自定义壁纸」开关与「自定义 Logo」（顶栏/登录页/ChatUI 品牌与 AI 回复头像统一替换）；指令管理新增冲突详情弹窗（主指令名 + 别名逐条列出冲突）；全局提示改为多条堆叠展示；修复深色模式指令名/别名看不清、顶栏按钮透明度不一致、移动端侧边栏过透等问题。

### 新增

- **ChatUI 面板透明度**：ChatUI 侧边栏底部「设置」菜单新增「面板透明度」滑块（0-90%），独立控制 ChatUI 整体透明度；拖动即生效并保存（localStorage `chat_panel_alpha`），未设置时跟随「设置 → 外观」的全局板块透明度
- **自定义壁纸开关**：设置 → 外观「自定义壁纸」顶部新增「启用自定义壁纸」开关；关闭后壁纸隐藏恢复默认纯色背景，已设置的壁纸地址与透明度全部保留，重新打开即可恢复；关闭时下方壁纸控件整体置灰
- **自定义 Logo**：设置 → 外观新增「自定义 Logo」项，支持图片地址输入 / 本站上传（自动压缩到最长边 512px 内）/ 清除；保存后替换顶栏、登录页、ChatUI 侧边栏品牌、ChatUI AI 回复头像四处默认 Logo，浏览器标签页图标（favicon）同步跟随
- **指令冲突详情查看**：插件 → 管理行为 → 指令管理中，有冲突的指令在「有冲突」标签旁新增「查看」按钮，点击弹出「冲突详情」弹窗，逐条展示主指令名/别名分别与哪些插件的指令名/别名重复（一条指令可有多个冲突，各自独立一条）
- **全局提示多条堆叠**：全局提示（toast）由单条队列改为多条同时展示，新提示追加在下方、每条按超时自动消失、每条可点 X 单独关闭

### 体验优化

- **ChatUI 透明度统一**：侧边栏与主聊天区（含消息区、输入框）统一使用同一透明度，不再「侧边栏透明、主界面不透明」割裂；输入框删除硬编码背景，跟随同一透明度回退链
- **透明度滑块步进 1%**：ChatUI 面板透明度、平台日志面板透明度、壁纸透明度、板块透明度四处统一改为每 1% 进
- **指令管理搜索支持别名**：搜索框匹配范围扩展到指令别名，与指令名/描述/插件一样参与过滤
- **冲突详情弹窗可读性**：正文加大字号、橙色低饱和标题改红色加粗、插件名显示「显示名（插件ID）」
- **壁纸/Logo 上传超 10MB 提示修正**：专用文案「图片大小 {size} 超出 10MB 上限」并动态显示实际文件大小，不再误用「地址无效」
- **自定义壁纸透明度默认 50%**：壁纸透明度与板块透明度默认值改为 50%（已保存的设置不会被覆盖）

### 修复

- **深色模式指令名/别名看不清**：暗色主题下 `--astrbot-code-color` 被定义为深玫红与背景几乎融为一体，改用 on-surface（白）；别名 chip 显式使用亮色
- **初始化误写 ChatUI 透明度存储**：把「全局面板透明度」误当成 ChatUI 独立设置写入 localStorage 的问题，改为仅用户拖动滑块时持久化，无独立设置时保持跟随全局
- **顶栏按钮透明度不一致**：顶栏三条横杠按钮默认不透明 surface 背景，壁纸模式下比半透明顶栏突兀，改为跟随「界面板块透明度」设置
- **移动端侧边栏过透**：临时弹出侧边栏背景不透明度不低于 0.92、激活项高亮不低于 0.88，保证文字可读；桌面常驻侧边栏仍跟随原透明度

### 说明

- 更新后请**手动重启**一次服务（本次含后端改动：指令冲突详情、壁纸开关与 Logo 存储路由）
- 若面板显示异常，可用顶栏「强制刷新面板」或浏览器 Ctrl+F5
- 建议验证：设置 → 外观开启自定义壁纸开关/设置自定义 Logo；插件 → 管理行为查看指令冲突「查看」弹窗；ChatUI 设置菜单拖动面板透明度滑块
