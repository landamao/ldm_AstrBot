# [4.27.63] — 2026-11-15 — 数据统计页数字单位切换、更换插件源入口放开、上传 zip 安装修复、生图权限修复

本版以 WebUI 改进为主：**数据统计页新增数字单位切换**（万/亿、K/M/B、无单位三档，全局统一格式化）；**无仓库地址的插件也能手动更换插件源**；**重要通知复制按钮改为复制「标题 + 详情」**。后端修了两个实质问题：**上传 zip 安装插件必然失败**（v4.27.61 引入缓存机制时路径回填遗漏）与**生图权限两处缺口**（提示语 KeyError、LLM 工具端绕过管理员限制）。

## 🚀 新功能（WebUI）

### 1. 数据统计页数字单位切换

- 统计页顶部右侧新增单位选择：**万/亿**（默认）、**K/M/B**、**无单位** 三档，偏好存 `localStorage`。
- 概览卡片、消息总数、平台排名、模型调用排名、会话 Top10 与两张图表 y 轴统一按所选单位格式化，数字补单位后缀（条/词元）。
- 无单位模式下长数字自适应字号，不撑破卡片。
- 修复 ApexCharts 切换单位后 y 轴刻度不重绘的问题（图表按单位 key 强制重建）。

### 2. 更换插件源入口放开

- **无仓库地址的插件也能手动更换插件源**：菜单项不再置灰，对话框直接展开自定义地址输入。
- 修掉此前「更换插件源」入口对无 repo 插件不可用、必须先有安装来源的问题。

### 3. 重要通知复制按钮补上标题

- `copyDetail()` 改为复制「标题 + 详情」，按钮在仅有标题时也显示。
- `notifications.copy` 文案改为「复制标题和详情」。

## 🛠️ 重构与修复

### 4. 修复上传 zip 安装插件必然失败

v4.27.61 引入插件安装缓存后，`store_archive()` 会把上传包 `move` 进 `temp/plugin-install-cache`，之后仍用原路径 `plugin_upload_<文件名>.zip` 调 `install_plugin_from_file`，`zipfile` 打开直接 `FileNotFoundError` —— 上传安装 **100% 崩**，与文件名是否中文无关。

- `store_archive()` 成功后用 `resolve_archive()` 回填 `file_path`，取不到缓存包则明确报「保存插件压缩包失败」，不留到解压阶段再炸。
- 落盘名改用 `plugin_upload_<uuid4>.zip`，不再拼用户上传文件名，避开中文/超长/控制字符在容器 locale 下的编码问题与同名并发覆盖。
- 回收逻辑与 `install_plugin_from_file` 的 `release_archive()` 天然对齐。
- 桩测四场景（中文名上传 / cache_token 复用 / 缓存失败回退 / 路径穿越文件名）全过。

### 5. 生图权限修复：补 wake_prefix、LLM 工具端加管理员限制、去掉 `*` 兜底子指令

- `waking_check/stage.py` 兜底权限消息漏传 `wake_prefix`：非管理员发未匹配的 `/image` 子指令时，格式化提示语抛 `KeyError: 'wake_prefix'`，已补上。
- LLM 工具端 `ldmbot_generate_image` 与 `ldmbot_list_image_generation_models` 原先不检查管理员，普通用户可通过 Agent 绕过 `/image` 的仅管理员限制；新增 `_admin_only_deny()` 复用 `ImageCommands.admin_only()` 的配置判断，非管理员时返回拦截文案，与聊天指令权限逻辑保持一致。
- 删除 `builtin_commands/main.py` 中 `@image.command("*")` 兜底子指令：未匹配子指令与裸 `/image` 交由 `CommandGroupFilter` 抛错、`waking_check` 按框架格式发送（管理员见指令树，非管理员见权限提示）。
