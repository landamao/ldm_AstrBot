# [4.27.58] — 2026-10-30 — 上下文管理重构、重要通知系统、插件覆盖安装确认、静态资源缓存修复

本版包含四组改动：**上下文管理策略重构**（轮数 / 绝对 token / 窗口百分比三条件独立触发 LLM 压缩，移除全部自动截断，历史不再无声丢失）；**重要通知系统**（压缩失败等严重问题持久化通知，WebUI 铃铛 + help 指令可见，未读必须手动确认）；**插件覆盖安装确认**（同名冲突不再直接报死，版本对比后可确认覆盖，配置数据保留）；**WebUI 静态资源缓存修复**（index.html 不再强缓存一年，发版后普通刷新即可见）。

## 🚀 新功能

### 1. 重要通知系统

- 新增 `important_notifications` 持久化通知（启动自动建表，无配置项）：同一问题未读期间只累计发生次数不刷屏，已读后再次发生生成新提醒；**未读通知一直残留直到管理员手动确认**，打开面板/登录都不算已读。
- 通知写入路径全兜底，DB 异常只记日志，绝不影响 LLM 请求主流程。
- 接入点：上下文压缩失败（无压缩模型 / 压缩无效果）不再只进日志，首批判通知带触发原因与具体报错。
- WebUI 顶栏新增通知中心（铃铛 + 未读数徽标，60 秒轮询），每条未读单独「标记已读」；平台侧 `help` 指令开头对管理员直接插入「⚠️ 重要通知」清单（仅 `event.is_admin()` 可见）。
- 通知 API（`GET /api/v1/notifications`、`POST /api/v1/notifications/read`）带登录鉴权。

### 2. 插件同名冲突「覆盖确认 + 版本对比」

- 上传压缩包 / 仓库 / 直链安装插件时，同名目录已存在不再直接报「目录已存在」，而是弹确认对话框，`v-table` 对比「已安装版本 / 待安装版本」（读不到显示"未知"），确认后才覆盖。
- 覆盖只替换插件代码目录，**插件配置（data/config）与数据文件保留**；确认弹窗 persistent 防误关，对话框明确提示覆盖不可自动回滚。
- 同名冲突不计入「失败插件」面板（清理临时目录后作为可恢复警告处理）；API 新增 `overwrite` 字段，缺省 False，旧客户端行为不变。

## 🛠️ 重构与修复

### 3. 上下文管理策略重构：三条件触发压缩，移除全部自动截断

- 新逻辑：**对话轮数 / 上下文绝对 token / 模型窗口百分比**三个条件独立判断，任一命中即触发一次 LLM 压缩（保留最近 N 轮原文，更早轮次生成摘要替换）；填 0 或 -1 表示该条件不参与判断。
- **自动路径不再有任何截断**：删除轮数超限硬截断、压缩后对半截断、压缩失败回退截断三条丢历史路径；压缩失败 / 无压缩模型一律原样发送 + 警告 + 重要通知，历史零丢失。`/compact yes` 手动截断逃生门保留。
- 配置变更：`max_context_length` 默认 -1 → **60**；新增 **`context_max_tokens`（默认 128000）**；`context_compress_threshold` 默认 0.82 → 0.8；删除 `context_limit_reached_strategy` / `dequeue_context_length` / `llm_compress_keep_recent_ratio` 三个配置项。
- **配置迁移全自动**：启动时自动移除已删除的旧 key、自动补新 key 默认值，存量用户零手工迁移；默认即开启，新装用户不会默认无限制聊到溢出窗口。

### 4. WebUI 静态资源缓存策略修复

- 修复入口 `index.html` 也被 `immutable` 强缓存一年、发版后强刷都看不到新版的问题：带 hash 的 `assets/` 产物保持一年 immutable，**index 与其余静态文件改 `no-cache` 协商缓存**（未变 304，有变立即拿到新版）。
- 修复 gzip 缓存不失效：`.gz` 比源文件旧时自动重压，手动覆盖同名文件的部署方式不再吐旧压缩内容。
- 本次更新后浏览器里的旧入口页还需**最后一次 Ctrl+F5**，此后发版普通刷新即可见。

### 5. CLI 交互模式补横幅豁免

- `--restore-backup` / `--恢复备份`（交互式恢复数据备份）启动时不再被横幅动画干扰，直接进入交互；既有 `--help`、`--reset-password`、`--rollback` 豁免与正常启动行为零变化。

## 📌 升级说明

- 更新后重启生效；首次启动自动建 `important_notifications` 表、自动迁移上下文配置（删 3 个旧 key、补 1 个新 key），无需手工处理。
- **行为变化提示**：`max_context_length` 原来是 -1（不限）的存量用户升级后维持"轮数不判断"；新增的 `context_max_tokens=128000` 与 80% 窗口比例立即生效，长对话到阈值会触发 LLM 摘要压缩而不是截断。想要旧式"到轮数就丢"没有对应选项了，压缩模型不可用时会原样发送并产生重要通知。
- 覆盖安装插件有固有风险（旧目录已删、新包加载失败时不可自动回滚），确认弹窗有提示；需要连配置数据一起清仍走「卸载」。
- WebUI 请 **Ctrl+F5 强制刷新一次**（本次是旧缓存头的最后一次）；此后发版普通刷新即可见新版。
- 详细变更见「详细变更日志/v4.27.58/」。
