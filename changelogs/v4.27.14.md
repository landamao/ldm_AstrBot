# [4.27.14] — 2026-08-30 — 内置生图（提供商 / LLM 工具 / ChatUI 生图会话）、/about 与关于弹窗、更新日志面板化、多项稳定性修复

本次更新包含 11 项新增、9 项体验优化、9 项修复。全部为 ldmbot 本地改动。

### 新增

- **生图模型提供商体系**
  - 新增「生图」类型的模型提供商，与普通对话提供商并列。模型提供商页新增「生图」页签，使用与对话模型一致的布局，可管理生图 API 源与模型列表
  - 内置 **OpenAI 兼容生图适配器**，支持常见的 OpenAI 兼容生图网关：
    - OpenAI 官方（dall-e / gpt-image 系列）
    - 火山引擎 Ark Seedream
    - 阿里云百炼兼容模式
    - 其他 OpenAI 兼容网关
  - 参考图生图：传了参考图时优先走图片编辑接口，网关不支持时自动回退到普通生成接口（兼容火山 Seedream 写法）
  - 返回结果统一转成 base64 展示（URL 形式的结果会自动下载后转换，按返回类型自动识别）；支持多个 API key、网络代理、自定义附加参数；超时默认 300 秒，单次最多生成 6 张
  - 连通性测试只查询模型列表，不会真的生成图片，避免测试时产生费用
  - 新增配置项 **「默认生图模型」**：在设置中可用专用下拉选择。当 LLM 生图工具、ChatUI 生图会话未手动指定模型时，用它作为全局兜底；留空则自动使用第一个可用的生图模型

- **LLM 内置生图工具**（开关：设置 → 生图，默认关闭）
  - `ldmbot_generate_image`：按提示词生成图片，可指定模型（按提供商 ID 或模型名模糊匹配）、参考图（本地路径或链接，最多 10 张）、尺寸、数量（1–4 张）；生成结果会以图片形式直接返回给模型，由模型发送给用户
  - `ldmbot_list_image_generation_models`：向模型列出可用的生图模型清单，帮助模型把正确的模型 ID 传给生图工具
  - 工具列表页会显示未注入的原因（如开关未开启、没有可用的生图模型），方便排查

- **ChatUI 生图会话**（与普通聊天会话完全隔离）
  - 侧栏新增「创建生图会话」按钮；生图会话类型会持久化保存，旧数据自动迁移，无需手动处理
  - 独立的生图模型选择器：顶栏模型菜单会按会话类型自动切换，在生图会话里选生图模型、在聊天会话里选对话模型，互不干扰
  - 图片尺寸设置：提供常用预设（1:1 / 3:2 / 2:3 / 2048×2048 高清），也可自定义宽高（16–8192），留空由模型自行决定；会记住上次的选择
  - 支持参考图：点击历史消息图片上的「引用图片」，即可把该图片加入输入区待传，作为下一次生图的参考
  - 生图失败会以 bot 消息的形式保留在会话中（刷新后仍可见）；最后一条 bot 消息支持一键重试（沿用原提示词与参考图，并自动删除旧的失败消息）
  - 首次进入生图会话会弹出「生图会话说明」（每个浏览器只弹一次）
  - 生图会话内隐藏模型配置 / 人格 / 流式 / 推理 / Fallback / 语音输入等对话相关开关；消息不可编辑；上传菜单变为「上传图片」且只接受图片

- **`/about` 指令与 WebUI「关于 ldm」弹窗**（替换原开源社区介绍页）
  - 新增内置指令 `/about`：以纯文本返回 ldm 版本（含 WebUI 版本）、系统信息（操作系统 / 版本 / 架构 / Python；Windows 上会把 build 22000 以上的 "10" 正确显示为 "11"）、启动目录 / 启动命令 / 启动时间 / 已运行时长、数据 / WebUI / 备份 / 版本回滚目录，以及项目主页与作者主页
  - WebUI 顶栏账户菜单新增「关于」项：点击弹出「关于 ldm」弹窗，实时展示同一套系统与运行信息，并提供「项目地址」「作者 GitHub」跳转链接

- **WebUI「更新日志」改为按版本加载**
  - 后端按版本逐个读取更新日志，每个版本对应一份文件（已拆分 v4.26.6 – v4.27.13 共 45 个版本）
  - 侧栏「更新日志」按钮改为打开新版按版本浏览的弹窗；「官方文档」仍读取项目说明文档，行为不变

- **会话批量删除**：会话列表支持进入多选模式，勾选多个会话后一键删除（带确认与结果提示）；若删除的会话中包含当前正在使用的会话，会自动开启一个新会话

- **消息内容「原始 / 渲染」切换**：每条 Markdown 消息可在渲染后的效果与原始文本之间切换查看

- **「填入输入框编辑」**：普通聊天消息可一键把内容填回输入框，修改后重新发送

- **图片消息悬浮操作**：鼠标悬停图片（触屏设备常显）出现操作条——支持**下载图片**；生图会话中另有**引用图片**按钮

- **空会话防重复新建**：当前会话为空时再点「新建对话」，改为提示「当前已在新会话」，不再反复堆叠空会话

- **会话自动命名持久化**：首条消息触发自动命名时同步写入后端，刷新页面后不再回退成「新的聊天」

### 体验优化

- **模型列表获取失败统一报错**：OpenAI 兼容 / Anthropic / Gemini 三类来源获取模型失败时，记录完整日志并统一抛出中文错误「获取模型列表失败：…」；OpenAI 兼容来源不再只认 404 一种情况，第三方网关以其他方式报错也能给出可读提示；WebUI 配置页会同步展示该错误

- **提供商相关错误消息全面中文化**：ID 缺失 / ID 已存在 / ID 不存在 / 提供商源不支持获取模型列表等提示全部改为中文

- **Token 估算对中文更准**：工具调用参数中的中文不再按转义序列统计，计数更贴近真实消耗

- **表格截断内容点击查看全文**：插件面板的工具表 / 命令表中，被省略号截断的单元格（描述、来源名称、配置标签、「未启用」原因等）点击后弹窗显示完整内容——手机端无法悬停查看的替代方案

- **UI 偏好同步机制重写**：侧栏自定义 / 主题色 / 壁纸 / Logo / 登录壁纸改为以服务端为唯一数据源，本地仅作首屏缓存；服务端没有设置时清除本地缓存，不再把本地值回传服务端——避免同一端口多实例之间偏好互相串味

- **面板底色跟随「板块透明度」**：管理面板外壳背景接入设置 → 外观的全局板块透明度，未设置时保持不透明

- **图片预览浮层重构**：大图容器支持上下滚动（手机端下滑即可看到关闭按钮）、新增明确的关闭按钮、预览图高度调整以适配更多屏幕；遮罩不再套用壁纸面板的半透明 / 模糊效果

- **工具调用卡片标题完整显示**：不再单行省略，窄屏下自动换行展示完整标题

- **Provider 工作区内嵌优化**：聊天页内嵌的模型提供商页面改用完整布局并支持滚动，替代旧的窄内嵌面板

### 修复

- **Open API WebSocket 发送消息报错**：通过 Open API 的 WebSocket 发送消息时偶发异常导致发送失败，现已修复；管理员权限判断改为使用认证时返回的 API key 自身权限

- **WebChat 工具卡片永久转圈**：WebChat 渠道实例被改过名（如改成 "ldm"）后，工具执行结果丢失导致卡片一直转圈，现已修复——改名后工具卡片也能正常显示结果与结束时间

- **历史消息中的工具调用状态错误**：已完成的工具调用在历史消息中误显示「运行中」、负时长被丢弃的问题，现已修复——没有结束时间的工具调用一律按已完成处理

- **工具执行期间直发内容冲掉工具卡片**：模型在工具执行期间直接发送文字时，会把正在执行的工具卡片顶掉、出现没有结果的孤儿卡片。现已修复：ChatUI / 直连聊天 / Open API 三条流都会等工具调用结束后再落库，工具卡片按原位置插回

- **设置项并发保存偶发报错**：多个请求同时写入同一设置项时可能撞唯一约束报错，现已改为原子写入，并发保存不再出错

- **端口占用检测误报**：启动时端口占用检测只统计 LISTEN 状态连接，不再被 TIME_WAIT 等残留连接干扰导致误报

- **数据目录定位跟随源码根**：从任意工作目录启动都能正确找到源码根下的数据目录，不会再在别处新建一份数据目录；版本回滚的目录解析逻辑同步修正

- **「新增提供商」下拉出现重复的生图类型**：默认模板中的友好命名条目与原始类型名条目重复显示，现已按类型去重

- **触屏设备误弹软键盘**：在触屏设备上打开 / 切换会话、发送消息后不再程序化聚焦输入框，避免误弹软键盘

### 说明

- 本次涉及数据库结构变更（生图会话需要新增类型字段），首次启动会自动迁移，无需手动处理
- 更新后请**手动重启**一次服务
- 若面板显示异常，可用顶栏「强制刷新面板」或浏览器 Ctrl+F5
