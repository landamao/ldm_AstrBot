# [4.27.51-beta.1] — 2026-10-21 — 模型与提供商作用域重构、配置项 ID 与模型同步

本 beta 版重构了 `/model`、`/provider` 的作用域：模型选择不再改动共享的提供商实例，而是按「自定义规则 > 当前会话 > 全局」三档持久化；同时把配置项 ID 与 `model` 强制对齐，切换模型会选中或创建 `来源/模型` 配置项，WebUI 对话模型链显示的 ID 就是实际模型。

## ✨ 新增（2项）

### 1. `/model`、`/provider` 三档作用域与 `-save` / `-global`

`/model <编号/模型名>` 默认只对当前会话生效：有自定义规则时写入规则（`session_service_config.model` + `model_provider_id`），没有规则时写入会话级覆盖（`session_model_override` + `session_provider_override_chat_completion`），不再调用共享实例的 `set_model()`。`-save` 强制写入自定义规则（没有就创建），`-global` 把对应配置项设为全局默认对话模型。`/provider` 同理，并支持直接写配置项 ID。详见[详细日志](../详细变更日志/v4.27.51-beta.1/变更日志-2026-10-21-模型与提供商作用域重构.md)。

### 2. 配置项 ID 与 `model` 强制同步

配置项 ID 统一按 `{provider_source_id}/{model}` 生成。切换模型时优先选中 ID 或 `model` 精确匹配的配置项；上游模型还没有配置项时自动按来源模板创建。启动时会修复历史失配 ID（例如 `懒大猫模型/test` 的实际模型是 `喜欢懒大猫`，会改名为 `懒大猫模型/喜欢懒大猫`），并同步 `default_provider_id`、`fallback_chat_models`、压缩模型、TTS/STT、规则与会话覆盖里的引用。详见[详细日志](../详细变更日志/v4.27.51-beta.1/变更日志-2026-10-21-配置项ID与模型同步.md)。

## 🛠 改进（2项）

### 1. 上下文窗口按本次生效模型计算

原先 `max_context_tokens` 会缓存到共享的 `provider_config` 上，首个请求的模型会把窗口值固定下来，不同会话切换到其他模型后会沿用错误窗口。现在按 `req.model or provider.get_model()` 逐请求计算，并显式传给 Agent；用量日志与统计也记录实际生效模型。详见[详细日志](../详细变更日志/v4.27.51-beta.1/变更日志-2026-10-21-上下文窗口与用量归因.md)。

### 2. 指令显示与 WebUI 规则兼容

`/model` 列表和切换回执显示完整配置项 ID（含来源），`/provider` 列表显示 `配置项ID · 模型`；WebUI 自定义规则编辑器保存时会保留 `/model` 写入的 `model` / `model_provider_id` 字段，不会被表单覆盖。详见[详细日志](../详细变更日志/v4.27.51-beta.1/变更日志-2026-10-21-指令显示与WebUI规则兼容.md)。

## 🐛 修复（2项）

- 修复 `/model` 修改共享 provider 实例导致同一提供商下的其他会话被连带换模型的问题。
- 修复配置项 ID 与 `model` 失配时，WebUI 对话模型链只显示配置项 ID、用户无法判断实际模型的问题。

## 📌 升级说明

- 更新后重启生效；无数据库结构变更，但会改写配置文件里的提供商 ID 与相关引用。
- 启动修复只处理 ID 以 `provider_source_id/` 开头的自动命名配置项；手填 ID（如 `my-gateway`、`硅基`、`语音转文本`）不会被改名。目标 ID 已存在时跳过改名并打警告，避免撞车。
- `-global` 现在只设置 `provider_settings.default_provider_id`，不再修改配置项的 `model` 字段；切换模型请使用 `/model <模型名/配置项ID>`，需要固定到全局时再加 `-global`。
- 会话级选择保存在 UMO 偏好里，重启后仍然有效；删除该会话的所有规则会一并清空会话级覆盖。
- WebChat 界面按消息发送的 `selected_model` 仍是最高优先级，会覆盖规则/会话选择。
- 本版本为 beta 测试版，建议先在测试会话验证：`/model` 切换、`/model -save`、`/model -global`、重启后默认模型链与规则是否一致。
