# [4.27.28] — 2026-09-14 — 上下文压缩轮次保留、/compact 手动压缩与模型引用管理页面

本版本围绕上下文管理全面增强：新增 `/compact` 手动压缩指令、压缩保留最近 N 轮全面接入自动路径并开放配置、压缩触发阈值可配置、`/status` 上下文展示重做，并新增「模型引用管理」页面，模型失效后不再逐个配置页去找。

## ⭐ 重点新增（2项）

### 1. 新增 /compact 手动压缩指令

新增 `/compact` 指令，随时手动触发上下文压缩，不必等占用超过阈值自动触发。

- `/compact`：仅 LLM 摘要压缩，无可用压缩模型时不会自动回退截断，会提示改用 `/compact yes`。
- `/compact yes`：允许无压缩模型时按轮次截断兜底。
- `/compact 3`：LLM 摘要压缩并保留最近 3 轮对话原文。
- 不带轮数时默认读取「压缩时保留最近对话轮数」配置，与自动压缩保留策略一致；显式指定 N 仍优先。
- 执行前自动停止本会话活跃 Agent，避免压缩中历史被写回；成功后回复压缩方法、轮数变化与占用变化。
- 第三方 Agent（dify / coze / dashscope / deerflow）会话不支持，直接拒绝。

### 2. 模型引用管理页面：一键扫描散落各处的模型配置，在一个页面快速配置

新增 WebUI 页面（侧边栏「更多功能」→「模型引用管理」），一键扫描主配置（含全部配置档案）与全部插件配置中的模型选择项及对模型 ID 的引用。某个模型崩溃/失效后，在列表里即可批量改掉，不再逐个配置页去找。

- 扫描范围覆盖：对话模型链、图片转述、生图、STT/TTS、上下文压缩、群聊图片转述等主配置项与全部插件配置；无模型选择标记的插件配置按「值命中提供商 ID」做疑似引用兜底识别。
- 表格展示来源（主配置档案/插件名）、配置项、类型（对话/生图/语音识别/语音合成/向量/重排/Agent 执行器）、状态（正常/已失效/未配置）与当前模型选择。
- 行内弹窗改模型：与插件配置页一致的提供商选择器，可搜索、按类型过滤，确认即保存；对话模型链整行维护（第一项主模型 + 回退列表，自动保持「回退不含主模型」）。
- 批量模式：按类型锁定勾选，跨类型行自动跳过并提示；「应用替换」批量改模型、「清除模型」批量设为未选择，逐条提示后弹统计。
- 修改即时生效：插件配置保存后自动热重载，主配置保存后管道即时重载；失效 ID 允许故意写回保留引用，由列表持续标红提示。
- 进入页面不自动扫描，点「开始扫描」才拉取，只读展示不改配置。

## ✨ 体验优化（3项）

### 1. 压缩保留最近 N 轮接入自动路径并开放配置

「保留最近 N 轮」此前仅 `/compact` 指令可指定，现在全面接入自动压缩路径，并新增 WebUI 配置项「压缩时保留最近对话轮数」（默认 5）。

- 大于 0 时自动压缩精确保留最近 N 轮对话原文，更早轮次进摘要，优先于按比例保留；设为 0 恢复旧的按比例保留行为。
- 注意：默认行为从「按比例保留约 15%」变为「精确保留最近 5 轮」，依赖旧行为的部署请把该配置设为 0。
- 配置显示条件与压缩提示词、保留比例一致：上下文超限策略为「由 LLM 压缩上下文」且使用本地 Agent 执行器。

### 2. 压缩触发阈值可配置

新增配置「上下文压缩触发阈值」（默认 0.82，滑条 0.5–1.0）：上下文占用达到模型窗口的该比例时触发压缩/截断策略，压缩后仍超限时的对半截断判断同样使用该值。对「按对话轮数截断」与「由 LLM 压缩上下文」两种策略均生效。

### 3. /status 上下文展示重做

- Token 数字改为 k / M 格式（如 `2.94M`），不再出现裸 9 位数。
- 新增「当前上下文」：优先取模型最近一次返回的真实占用，模型未返回时退回历史消息本地估算，来源标注清晰。
- 新增「历史消息轮数」统计。
- 原先的「总计」改为「累计消耗」，明确是本对话累计 API 计费消耗（输入/缓存/输出分列），避免被误解为当前上下文长度。

## 🛠️ 问题修复（1项）

### 1. /compact yes 截断轮数读取错误

`/compact yes` 的截断兜底原先读取不存在的配置键（固定只丢 1 轮），现改读「轮次超限时一次丢弃轮数」配置；未显式传轮数且配置了保留轮数时，同样按「保留最近 N 轮」截断，与 LLM 摘要路径对称，不再逐步丢轮。
