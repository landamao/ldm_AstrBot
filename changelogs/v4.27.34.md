# [4.27.34] — 2026-09-19 — 壁纸透明度体系重设计、ChatUI 气泡化与启动引导、状态回执增强

本版本以 WebUI 视觉体系重设计为主：壁纸始终完全显示、板块透明度只作用于板块、页面大块容器保留一层底、ChatUI 页面透底 + 消息气泡半透明化；同时把 .env 示例模板改写为社区惯例的 .env.example，/status 回执新增「最后活跃时间」。

## ⭐ 重点新增（1项）

### 1. WebUI 壁纸与板块透明度体系重设计：壁纸完全显示、板块透明不再叠白布、ChatUI 气泡化

#### 背景

旧透明度体系存在三类问题：

- 「壁纸透明度」滑块让壁纸永远蒙着一层灰，壁纸类图片被压得发暗；
- 「界面板块透明度」实际作用于整页与多层容器：提供商页骨架五六层、配置页行容器多层、表格从根元素到 td 最多六层都上色，50% 半透明白叠加后等效 95%+ 不透明，等于实心白布，代码里明确声明透明的容器也会被强行涂色；
- ChatUI 整页一张固定白布，bot 消息文字没有小块承载——布透明文字看不清，不透明又完全看不到壁纸。

经四轮反馈定案最终格局：整页透 → 页面大块底层容器保留一层 → 板块/卡片再叠自己的层。

#### 核心改善

- 移除「壁纸透明度」滑块，壁纸层不再叠加透明度，壁纸始终完全显示；旧配置里的 opacity 字段读取时自动丢弃，下次保存自然清除，无需迁移。
- 「界面板块透明度」回归本义，只作用于板块：数据统计、追踪、插件详情、知识库详情、配置页、提供商页等页面大块底层容器各保留一层半透明底，保证文字看得清；大块内部骨架、行容器、表格内部一律透明防叠加，表格底色只由表格根一层承担，行悬停高亮不受影响。
- 代码里明确声明 background-color: transparent 的容器（如插件页外层卡片）不再被强制涂色。
- ChatUI 气泡化：壁纸激活时页面与输入区衬底透明，直接露出壁纸；原整页底色移到消息气泡上——bot 气泡与用户气泡用半透明底色承载文字，侧边栏/输入条自动成为半透明板块；未设置壁纸的界面保持原观感。
- 板块透明度上限从 90 放开到 100，支持全透明板块。

#### 使用方式

设置 → 外观 中重新调整：壁纸透明度入口已移除；「界面板块透明度」滑到 100 可获得全透明板块，ChatUI 面板透明度跟随同一数值。更新后浏览器 Ctrl+F5 强刷一次即可看到新格局。

## ✨ 体验优化（2项）

### 1. .env 示例模板改写为 .env.example，模板与真实配置分离

#### 背景

此前首次启动时，框架会把全部处于注释状态的示例模板直接写为 `.env`：模板与真实配置混用同一个文件名，没有「模板 / 配置」之分；想对照干净模板或恢复初始说明时没有参照，打包备份时也容易把这份全注释的 `.env` 当成用户配置一起带走。该行为与社区「.env.example 作模板、.env 作真实配置」的惯例相反。

#### 核心改善

- 首次启动自动生成的示例模板落盘为 `.env.example`，已存在则永不覆盖；真实 `.env` 存在即加载，加载逻辑不变。
- 模板头部说明同步改写：「本文件是示例模板，不会被自动读取；复制一份并重命名为 .env 后启动时自动读取」。
- 存量用户的 `.env` 完全不受影响：继续照常加载，永远不会被重新生成或覆盖；若还没有 `.env.example`，下次启动会补生成一份作对照。

#### 使用方式

新装用户：首次启动生成 `.env.example` → 复制重命名为 `.env` → 取消注释需要的变量 → 重启生效。

### 2. /status 回执新增「最后活跃时间」

/status 回执在「对话 ID」之后新增一行「最后活跃时间」，取自对话的更新时间（对话内容、标题、人格等落库更新时自动刷新），与 /ls 列表的「上次更新」同一数据来源、同一「MM-DD HH:MM」格式；缺失时显示「未知」。跨会话 `/status <目标>` 同样显示目标对话的最后活跃时间——翻旧对话或跨会话查看时，一眼判断对话是刚才还在聊还是早已沉寂。

只发指令、不触发 LLM 或对话更新的操作不会刷新该时间。
