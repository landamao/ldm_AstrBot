# [4.26.40] — 2026-08-21 — 插件图标自定义 Logo 兜底、plugin help 详情化、flow unset 显示全局配置

基于 ldm v4.26.39 的版本。本次为插件没有图标时 WebUI 各处插件图标统一显示自定义 Logo（未设置时回落默认 Logo）；/plugin help 输出改为详情卡片式（字段逐行展示，空值不显示）；/flow unset 回执补充当前全局流式配置状态。

### 新增

- **插件图标自定义 Logo 兜底**：插件没有图标（或图标加载失败）时，WebUI 各处插件图标统一显示自定义 Logo——已安装插件卡片、插件市场卡片、插件详情页、安装/更新对话框；未设置自定义 Logo 时回落默认 Logo（icon-no-shadow.svg），不再显示旧的 plugin_icon.png 占位图；统一走 useCustomLogo composable，设置页保存自定义 Logo 后即时广播刷新，无需重进页面

### 体验优化

- **/plugin help 详情化**：输出改为详情卡片式，标题「✦ 插件详情: xxx ✦」，字段逐行展示（插件名 / 显示名 / 版本 / 作者 / 描述 / 仓库 / 帮助 / 依赖 / 平台 / 文件 / 安装目录 / 最后更新），空值字段整行不显示；新增「安装目录」字段（插件安装目录绝对路径）、「最后更新」字段（以插件 metadata.yaml/yml 修改时间为准）、「文件」字段（main.py / 配置面板 / README / CHANGELOG 关键文件状态）；保留原有指令列表与唤醒前缀提示；内置指令插件 builtin_commands 新增 display_name「内置指令插件」，版本号 0.0.1 → 0.0.2
- **/flow unset 显示全局配置状态**：取消当前会话流式输出设置（含未设置时）的回执追加一行「全局配置：开启/关闭」，展示恢复跟随全局配置后实际生效的流式状态

### 修复

- 本次无修复内容；全部为 ldmbot 本地新增与优化。

### 说明

- 更新后请**手动重启**一次服务（本次含后端改动：plugin help 详情化、flow unset 全局配置回执）
- 若面板显示异常，可用顶栏「强制刷新面板」或浏览器 Ctrl+F5（前端改动有 immutable 长缓存）
- 建议验证：聊天执行 /flow unset 查看全局配置；插件 → 已安装，找一个无图标插件确认显示自定义 Logo
