# [4.27.23] — 2026-09-05 — 修复静默无回复与悬空消息、模型选择器失效治理、平台日志白色遮罩根修、外观透明度失灵修复

本版本包含 4 项修复：2 项对话与模型选择治理，2 项 WebUI 透明度体系。各变更的完整细节见项目「详细变更日志/v4.27.23/」目录。

## 🛠️ 问题修复

### max_step 收尾幻觉工具调用导致静默无回复并残留坏消息

Agent 达到步数上限（max_step）强制收尾时，模型仍可能「幻觉」输出工具调用：本次运行静默无任何最终回复（用户只看到卡住的「调用工具」状态），且一条协议非法的残缺消息被持久化进历史，之后每轮对话都报 400。现三重防护：拦截幻觉调用并正常收尾（纯幻觉无文本时补一条「工具调用次数已达上限，未能生成最终回复」保证有可见回复）；组装前按工具调用 id 配对补齐缺失结果；落库前丢弃悬空工具调用消息并清理已中毒的存量会话。对照上游 PR #9913 实现并追加两层防护。

### 模型选择器失效模型治理：删除残留根因 + 只显示启用 + 失效标注

已删除的模型「时有时无」残留在各选择器（后端 `delete_provider` 漏同步内存配置，现已根治）；已禁用的模型照常出现在提供商/模型链/知识库各下拉里（各选择器统一只显示启用的模型）；已被引用的模型失效后界面静默显示原名（现显式标注「已失效」，WebChat 模型按钮、模型链、配置字段、知识库回显全覆盖）。

### 平台日志「白色遮罩」根修，透明度只作用于黑色日志区

旧版日志页整页（含上方标题、按钮区）套半透明背景，滑块连上方区域一起变，浅色主题下像蒙白色遮罩。现独立滑块（更名「背景透明度」）只作用于黑色日志终端区；日志页页面底整层取消、壁纸直接可见；标题栏与筛选控件行各留一个跟随全局板块透明度的圆角小块底色，亮壁纸上依然可读。排查确认白色感另一来源：壁纸透明度低于 100 时壁纸与页面白底掺白，建议壁纸保持 100 全彩显示。

### 外观设置板块透明度低于 50 保存后变 0、壁纸透明度最高只能存 50

板块透明度滑到 50 以下保存重开直接变 0（板块彻底不透明），根因是保存时被错误钳制到最低 50、而恰好等于默认值的字段省略不存、重读时缺字段被兜底成 0；壁纸透明度想调得更实（50 以上）也一直存不进去。现钳制范围恢复设计值（板块 0-90、壁纸 10-100），读取兜底改用默认值常量。

## 📌 升级说明

- 含后端修复（max_step、delete_provider），更新后请手动重启 ldm；WebUI 部分刷新页面即可，如仍显示旧界面请 Ctrl+F5 强制刷新。
- 壁纸建议保持「壁纸透明度」100：低于 100 会与页面白底混合发白，属壁纸淡化的固有表现，不是故障。
