# [4.27.44] — 2026-10-10 — on_waiting_llm_request 提前触发与群聊提示词精简

本版本两条主线：一是把 on_waiting_llm_request 钩子（连同「正在输入」指示）的触发点从「打断收尾/追补排队/会话锁之后」提前到「防抖一结束就发」，兑现「进入 LLM 流程即通知」的语义；二是延续提示词纯描述化方向，把群聊历史块里 @ 机器人/@ 全体的醒目警告标记改为平实的内联标注，并精简群聊上下文与空唤醒的注入文案。原先计划在框架内做的「@ 自身保留给 LLM」改为插件实现：[ldmpl-reself-at](https://github.com/landamao/ldmpl-reself-at)。

## 🛠️ 问题修复（1项）

### 1. on_waiting_llm_request 在活跃回复期间触发过晚

钩子名义语义是「等待调用 LLM（仅通知）」，但旧触发点排在打断收尾等待、追补排队、会话锁之后：机器人正在回复时同一发送者再 @ 它，钩子要等这一整轮 LLM 结束才触发，依赖它的插件（如消息回应类）拿到的通知完全失去时机。现在 send_typing 与钩子在防抖结束后立即执行——进入 LLM 流程那一刻就通知，早于追补排队/打断收尾/会话锁。

行为变化（插件开发者注意）：

- 追补被并入活跃轮消费的路径，钩子现在也会触发（旧位置该路径不触发）。
- 钩子内终止事件（stop）现在拦在追补排队之前，事件不进入任何排队。
- 「正在输入」状态指示随通知一起提前发送。

## ✨ 体验优化（2项）

### 1. 群聊历史块 @ 标记改为平实标注，自身艾特保留交由插件实现

历史块里 @ 机器人的记录原先整条前插「⚠️[DIRECTED AT YOU] 」，@ 全体成员也共用同一前缀（语义过强——@ 全体并不是定向 @ 机器人）。现在改为在 @ 处内联标注：@ 机器人 → `[At: 名字(myself)]`；@ 全体与其他 @ 一致 → `[At: 名字]`，不再有任何整条前缀。「DIRECTED AT YOU」字样自此从代码库彻底移除。

原先设计稿中「当前消息 @ 自身保留给 LLM」的框架级注入不再内置，已做成独立插件 [ldmpl-reself-at](https://github.com/landamao/ldmpl-reself-at)，需要该能力的用户自行安装。

### 2. 注入提示词文案精简

延续「纯描述化、不下指令」方向（注入 LLM 的英文文案只陈述事实，回应方式交给模型结合上下文自行决定）：

- 群聊上下文块 header 缩短（「You are currently in a group chat」→「You are in a group chat」），footer 的 Above/Below 说明句收紧为「Above is the group chat history in chronological order. Below is the current user message to be processed.」。
- 空唤醒提示词去掉指令性的「Respond naturally based on the conversation context.」，缩短为「The user woke you up with an @ mention but did not include any content.」；判定逻辑（仅 @ 自身/@ 全体/唤醒前缀均算空唤醒）与落库行为不变。
