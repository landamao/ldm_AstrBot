# [4.27.6] — 2026-08-24 — 上传压缩包更新、autoReboot 开关、版本列表下载链接

本次为 4.27.5 之上的 WebUI 更新功能增强版本。新增上传压缩包一键更新功能（含文件完整性校验和两步危险确认），所有更新路径共用 autoReboot 自动重启开关，版本列表新增下载链接查看；修复 updator 旧版本回写掩盖缺失数据的问题。

### 新增

- **上传压缩包更新**
  - 更新弹窗新增「上传压缩包更新」入口，支持拖拽/点击选择 zip 文件
  - 上传后后端自动校验文件完整性：检查 main.py、astrbot/ 下 7 个一级子项、WebUI dist（index.html/version/assets/）是否齐全
  - 自动提取压缩包内程序版本号和 WebUI 版本号，前端弹窗展示
  - 校验不通过时：弹窗显示缺失文件列表（红色）和已存在文件列表（绿色），点「仍要继续更新」后弹出二次确认弹窗（3 秒倒计时 + 必须逐字输入「我确认继续更新，损坏后果自行承担」才能继续）
  - 校验通过时：弹窗显示已存在文件列表（绿色）+ 红字加粗后果提示，点「确认更新」后应用
  - 非 zip 文件上传时弹黄色提示，不再静默丢弃

- **autoReboot 自动重启开关**
  - 开关位于主更新弹窗，所有更新路径（版本切换 / 上传压缩包）共用
  - 开启：更新成功后自动重启服务
  - 关闭：更新成功后弹出小窗口询问是否立即重启
  - 重启确认弹窗提示 WebUI 已更新但程序代码可能不适配，建议立即重启

- **版本列表下载链接**
  - 版本列表表头新增「下载链接」列，每行可查看 zipball_url
  - 支持复制链接和直接打开链接

### 体验优化

- **更新弹窗交互**：上传压缩包更新入口与下载源选择区域并列展示，操作路径清晰
- **前端 API 新增**：v1.ts 新增 `uploadPackage(file, reboot)` 上传校验和 `applyUploadedPackage(zipPath, reboot)` 确认应用两个接口
- **i18n 文案**：header.json 新增 uploadPackage（含 verify 子对象）、autoReboot、restartConfirm、downloadLink 等中文文案

### 修复

- **updator 旧版本回写掩盖缺失**
  - `_应用webui()` 原来在更新包没有 version 文件时会回写旧版本号，导致用户看到「更新成功」但实际 WebUI 版本未变却被掩盖
  - 修复：去掉旧 version 回写兜底，缺失就是缺失，不掩盖

### 说明

- 更新后请**手动重启**一次服务
- 若面板显示异常，可用顶栏「强制刷新面板」或浏览器 Ctrl+F5
- 建议验证：更新弹窗 → 上传压缩包更新 → 选择 zip → 查看校验结果弹窗 → 确认应用；autoReboot 开关切换后更新验证自动/手动重启行为
