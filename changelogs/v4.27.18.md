# [4.27.18] — 2026-09-02 — /persona 远程换人格（会话ID参数）与 zip 中文文件名解压乱码修复

本次更新包含 1 项新增、1 项修复。全部为 ldmbot 本地改动，无官方上游合入。

### 新增

- **/persona 支持远程换人格（会话ID参数）与远程 reset**
  - `/persona <人格名> [会话ID]`、`/persona unset [会话ID]`、`/persona reset [会话ID]`：管理员可在聊天侧直接给其他会话（群聊/私聊/WebChat 线程）设置、取消人格并清空其上下文，无需对方自己执行指令
  - 会话ID 支持完整 UMO、群号/QQ号、WebChat 线程段、昵称、群名/发送者名；全部**精确匹配**不做子串匹配，防止输「12」误撞「123456」
  - 匹配到多个会话时拒绝执行并列出候选，未命中提示「未找到会话」；只剩昵称残留的死会话一律不认，防止死会话被远程建活
  - 目标会话有自定义规则人格时改规则值（实时生效）；无对话时自动创建对话并带上人格，对方下一条消息即用新人格
  - `/persona reset` 复用 /reset 核心清理链：停活跃任务、清对话历史、清群聊上下文与消息历史数据库记录；挂在 /persona 下而不是扩展 /reset，避免普通成员借参数远程清别人对话
  - 会话ID 省略时行为与旧版完全一致

### 修复

- **zip 中文文件名解压乱码**
  - 更新 ldm、安装插件、上传技能包、回滚等所有走 Python 解压的路径，压缩包内中文文件名/目录名不再变成乱码（如「详细变更日志」变成「Φ»ªτ╗å…」）
  - 根因：ZIP 条目未设 UTF-8 标志位时 Python zipfile 按 cp437 解码文件名；Info-ZIP 打包的发版包与 Windows GBK 工具打包的压缩包均无该标志
  - 修复方式：cp437 无损还原原始字节后按 utf-8 → gbk 顺序重试解码，无法解码的保持原样不抛异常；带 UTF-8 标志的条目与纯 ASCII 条目零开销跳过
  - Windows 上查看某些包正常、解压却乱码的现象就此消除

### 说明

- 更新后请**手动重启**一次服务
- 纯后端改动，无需强制刷新浏览器
- 建议验证：`/persona 人格名 群号` 远程换人格后对方下一条消息即用新人格；`/persona reset 群号` 清空对方上下文；更新 ldm 或安装插件后中文目录正常落地
