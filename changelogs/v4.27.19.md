# [4.27.19] — 2026-09-03 — 消息防抖、主配置恢复默认与指令体验全面优化

本版本集中提升日常使用体验、配置可维护性和消息处理效率，包含 3 项重要新增、3 项体验优化及 2 项问题修复。重点推荐关注「消息防抖」与主配置「恢复默认值」功能。

## ⭐ 重点新增

### 私聊消息防抖：连续刷屏只触发一次 LLM 请求

新增可配置的私聊消息防抖能力。用户在短时间内连续发送多条消息时，系统会等待静默窗口结束，将文本、图片、语音、文件、引用等原始消息组件合并后，只执行一次完整处理链路和一次 LLM 请求。

- 连发多条消息不再为每条消息分别请求 LLM，显著减少重复请求、无效计费和被打断的废弃结果。
- 合并内容使用 `[Message N]` 标记，并附带合并说明，模型和历史记录都能准确理解消息顺序与上下文。
- 图片、语音、文件、引用、视频等媒体仍按原有链路处理，不会因防抖丢失。
- 仅私聊生效，群聊和插件主动构造的 LLM 请求保持原行为不变。
- 支持静默窗口和累计等待上限，持续刷屏时到达上限会强制放行，避免无限等待。
- 配置实时读取，修改后无需重启即可生效；默认关闭，不影响已有用户行为。

配置位置：WebUI → 配置文件 → 扩展配置 → 分段回复与打断回复之间的「消息防抖」。

### 主配置新增「恢复默认值」按钮

主配置文件页面现在支持恢复默认值。仅填空类和数值类配置显示恢复按钮，开关、下拉框和特殊选择器不显示，避免界面出现过多干扰操作。

- 只有被修改且与默认值不同的配置项显示按钮。
- 支持 string、text、list、dict、int、float 类型。
- 恢复操作直接写回当前主配置，和插件配置页的使用体验保持一致。
- 修复管理员 ID、唤醒词等 list 配置项默认值注入错误，恢复时不会再被清空为 `[]`。

### 「关于」信息新增全局代理状态

`/about` 指令和 WebUI「关于 ldm」弹窗均新增「全局代理」信息，展示当前进程真实使用的代理状态，并区分启动环境变量、配置文件和清除系统代理等情况。

- 配置修改但尚未重启时，会明确显示当前实际代理以及「重启后生效」状态。
- 已清除系统代理时显示 localhost 直连信息。
- 两处展示统一使用当前实际生效的进程环境，避免配置页面与运行状态不一致时产生误导。

## ✨ 体验优化

### 内置指令参数处理全面统一

内置指令不再依赖框架是否把参数转换成 int。`/provider`、`/model`、`/key`、`/history`、`/switch`、`/reset scene` 等序号参数统一支持数字和数字字符串，并提供范围校验。

- 非法参数会指出参数名称和实际输入值。
- 超出范围时显示可用总数，而不是笼统提示「序号错误」。
- 缺少参数时补充完整「使用方法：」和具体示例。
- `/set`、`/unset`、`/image`、`/persona`、插件管理等指令的缺参和类型提示更加明确。
- 兼容框架传入 int、str、None 等不同形态，减少同一指令在不同平台表现不一致的问题。

### 分段回复默认值与配置界面优化

- 分段回复默认开启。
- 换行分段默认值改为可在 WebUI 中直接看见的字面量 `\\n`，实际分段行为保持不变。
- 默认超长整段发送阈值调整为 400 字，减少长回复被拆成过多短消息。
- WebUI 专业模式中，分段模式、正则和符号列表三项配置相邻展示，并按当前模式联动显示。
- 消息防抖配置与分段回复、打断回复在扩展配置中按功能关系集中展示。

### WebUI 人格切换与自定义规则联动

当会话存在自定义规则人格时，WebUI ChatUI 的人格切换现在会直接修改该规则并立即生效，不再出现「界面选了人格但下一条消息仍使用旧人格」的情况。

- 人格菜单会提示当前会话受规则强制，并说明切换会直接修改规则。
- 选择「不使用人格」会移除规则中的人格字段，同时保留其他规则配置。
- 聊天侧 `/persona` 修改规则后，WebUI 菜单会同步显示最新人格。
- 普通无规则会话继续使用原有对话级人格逻辑。
- 成功和失败 toast 反馈补齐，新增 8 项规则联动测试。

## 🛠️ 问题修复

### 统一 /about 与 WebUI 的 WebUI 目录显示

修复 `/about` 指令仍显示旧 `data/dist` 路径，而 WebUI 关于弹窗显示实际 `dashboard/dist` 路径的问题。现在两者使用同一目录解析逻辑；找不到可用目录时显示「未知」，不再拼接一个看似有效的虚假路径。

### 修复默认值元数据注入误判 list 配置

修复默认值注入逻辑把 list 元素描述误当成嵌套 object 的问题，确保管理员 ID、唤醒词等 list 配置能够正确获得默认值，并在 WebUI 中正确显示恢复默认按钮。
