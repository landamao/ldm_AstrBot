# [4.27.55] — 2026-10-25 — 插件详情页 LLM 工具新增「LLM 工具名」列

本版修复 WebUI 插件管理详情页中「LLM 工具」分组只显示处理函数名、看不到模型实际调用工具名的问题。

## ✨ 新增（1项）

### 插件详情页 LLM 工具表新增「LLM 工具名」列

- `@llm_tool(name="...")` 注册时把实际工具名记录到 handler 元数据，插件详情接口为 `llm_tool` 组件返回 `llm_tool_name` 字段。
- WebUI 插件详情页在「LLM 工具」分组的函数名后新增一列，以高亮代码样式显示工具名；悬停/点击可查看完整名称，移动端自动收窄列宽。
- 同一处理函数注册多个工具名时按注册顺序用 ` / ` 连接；未显式指定 `name` 时工具名与函数名相同，旧数据缺少该字段时显示 `-`。

## 📌 升级说明

- 更新后需重启机器人或重载插件，后端才会采集已加载插件的工具名；刷新 WebUI 后生效。
- 仅影响插件详情页展示，不改变工具注册、调用、权限或插件配置行为。
