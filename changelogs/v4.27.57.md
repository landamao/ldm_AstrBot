# [4.27.57] — 2026-10-30 — WebUI 对话模型链编辑体验重构

本版集中修复配置页「对话模型链」编辑器的一串交互问题。此前的拖拽排序走浏览器原生 HTML5 DnD，在部分浏览器（Safari、内嵌 webview、触屏）上不触发或拖拽影像异常，且整个条目都可拖，按在行内任意位置都会进入拖拽状态，把右侧上移/下移/删除按钮的点击全部吞掉；条目还命中了全局「Q 弹按压」动效，点一下整行缩放弹动。本版把拖拽整体换成 Sortable.js 并只保留手柄可拖，条目彻底静态化，弹窗里的链条目补齐了上下移按钮。

## 🛠️ 优化与修复（4项）

### 1. 拖拽排序换用 Sortable.js，仅手柄可拖

- 拖拽实现从原生 HTML5 drag events 整体替换为 `Sortable.js`（与插件排序同款依赖，未新增包）。
- `forceFallback: true`：不走浏览器原生 DnD，改用鼠标/触摸事件模拟，全平台表现一致，解决部分浏览器拖不动、拖拽影像异常的问题。
- `handle: '.drag-handle'`：只有左侧手柄能发起拖拽，条目本体只作为落点；上移/下移/× 按钮从此不再被拖拽抢占 mousedown。
- `fallbackOnBody: true`（克隆体挂 body，弹窗内滚动容器不裁剪拖拽影像）、`fallbackTolerance: 3`（移动 3px 才起拖，压住手抖）。
- 拖拽时原位置留虚线占位框（ghost），克隆体带阴影抬起，松手有排序动画。

### 2. 条目退出全局「Q 弹按压」，点击不再弹动

- 新增覆盖规则 `.v-list-item.chain-item:active { transform: none !important }`，特异性压过 `_override.scss` 里全局的 `scale(0.96)` 按压动效；点条目、按按钮时条目本体都纹丝不动（此前按 × 时条目作为 `:active` 祖先也在跟着晃）。
- 关闭条目的 hover/focus 蒙层（`.v-list-item__overlay`）与涟漪（`:ripple="false"`）：条目不可点击，不再有任何按下反馈。
- 其他列表（会话、插件等）的 Q 弹按压不受影响。

### 3. 添加模型弹窗补齐上下移按钮

- 弹窗里已选链条目的操作区从只有 × 扩成与主列表一致的上移/下移/删除三按钮，复用同一套 `move()` / `removeAt()` 逻辑与 i18n 文案；首项禁用 ↑、末项禁用 ↓。
- 弹窗内无需退出即可调序。

### 4. 列表 key 稳定化

- 两个列表的 `v-for` key 从 `chain-{id}-{index}` 改为 `chain-{id}`（链条本身已去重）：重排时不再整列重建 DOM，拖拽落位后视图平滑过渡，避免索引参与 key 导致的重渲染闪烁。

## 📌 升级说明

- 更新后重启生效；仅 WebUI 前端变更（`dashboard/dist`），无核心代码改动，无新增/移除配置项。
- 浏览器端有 `immutable` 长缓存，更新后请强制刷新（Ctrl+F5）才能看到新版界面。
- 拖拽手感说明：按住左侧手柄并移动超过 3px 开始拖拽；条目其余区域纯展示，点击无任何效果。
