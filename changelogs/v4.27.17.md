# [4.27.17] — 2026-09-02 — WebUI 目录迁移 dashboard/dist、版本回滚管理、消息多选删除、/upldm 一键更新指令

本次更新包含 4 项新增、5 项体验优化、3 项修复。全部为 ldmbot 本地改动，无官方上游合入。

### 新增

- **版本回滚管理（WebUI）**
  - 设置→维护新增「版本回滚」卡片：展示更新器自动保留的旧版本备份（版本/大小/时间），支持一键回滚（回滚后自动重启）、删除单个备份、清理全部备份
  - 回滚整包恢复旧版本源码与 WebUI；新版本运行正常时建议清理备份释放空间
- **ChatUI 消息多选删除**
  - 消息工具栏新增「多选删除」入口，按轮选择：点任何一条消息（含 bot 回复）选中它所在的整轮
  - 整轮连带删除：用户消息 + 该轮 bot 回复/报错/插件消息 + 关联分支一起删，大模型上下文同步移除对应轮次（不再记得被删内容）
  - 选中轮红色描边高亮，底部操作条显示已选轮数，删除前二次确认
- **聊天侧 /upldm 一键更新指令（管理员）**
  - 免开 WebUI：检查更新 → 镜像源下载最新整包 → 应用（自动备份旧版）→ 更新依赖 → 自动重启
  - 消息反馈完整：更新中、无更新提示、成功后版本对比、重启；启动报告插件照常发报告
- **模型选择弹窗搜索过滤**
  - 配置文件页、插件配置里的模型选择弹窗新增搜索框，按提供商 ID / 类型 / 模型名模糊过滤
  - 显示匹配计数，无匹配时显示「没有匹配的提供商」空态；每次打开自动清空搜索词

### 体验优化

- **/persona 与自定义规则联动**
  - 会话已配置自定义规则人格时，/persona 切换/取消直接改规则里的值，立即生效（原来只写对话数据被规则压制，切换意图完全丢失，还得去 WebUI 手动改）
  - 无规则人格的会话行为不变
- **更新弹窗按钮防重复触发**
  - 更新全流程期间「更新到此版本」「切换」「上传压缩包」「刷新版本信息」按钮保持禁用，不再产生并发更新任务
  - 双标签页场景：第二个标签页发起更新会转为显示已有任务的实时进度
- **更新互斥提示**
  - 更新进行中再触发更新，明确弹出红色提示「已有更新任务正在进行中」（原来静默转跟踪，无任何感知，容易误以为点了没反应）
- **插件管理 / 插件页面 / MCP 加载态区分**
  - 数据加载中显示进度条，不再闪现「暂无插件页面」等空态误导
- **文案与目录信息**
  - ChatUI 顶部模型菜单 4 处硬编码英文改中文（搜索模型或 ID、正在加载模型... 等）
  - 「关于 ldm」弹窗与 /about 指令目录补全「插件目录」「插件数据目录」

### 修复

- **WebUI 目录迁移：部署/运行第一优先改为项目根 dashboard/dist**
  - WebUI 本质是源码的一部分，随源码树走；data/dist 降为历史遗留回退
  - 解决「启动参数指定不同 data 目录导致 WebUI 直接用不了」的结构性问题——换 data 目录启动 WebUI 不再失效
  - 老部署（WebUI 在 data/dist）自动兼容继续可用，同步源码后 dashboard/dist 到位即自动切换；data 目录一律不清理（可能是用户自建内容）
- **WebChat 重试用户消息重复**
  - 对 bot 回复点「重试」，用户消息不再重复出现（原来每重试一次就多一条完全相同的用户消息）
  - 修复前已产生的重复历史消息仍在库中，删除对应会话即可，不做自动清理
- **自定义规则死条目**
  - 「添加规则」下拉不再出现大量已删除对话的 UMO（WebChat 旧聊天、分支尤多）
  - 删除会话时级联清理昵称记录与该会话的偏好残留，以后不再积压

### 说明

- 更新后请**手动重启**一次服务；若面板显示异常，浏览器 Ctrl+F5 强制刷新
- 建议验证：换 data 目录启动后 WebUI 正常；ChatUI 重试不重复用户消息；设置→维护「版本回滚」可见备份列表
- WebUI 位于 dashboard/dist，安装/更新脚本会自动清理旧 data/dist 残留
