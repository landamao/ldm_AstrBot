# [4.27.31] — 2026-09-17 — 火山引擎原生生图接入、提供商快捷复制与真实生图测试

本版本围绕生图接入、配置效率和模型排障展开：新增火山方舟 Seedream 原生生图适配，支持从对话提供商复制连接信息；模型引用管理增加类型与状态筛选；生图测试改为真正请求图片并校验保存，不再用「能获取模型列表」代替「能生图」。

## ⭐ 重点新增（2项）

### 1. 火山引擎生图：原生适配方舟 Seedream，文生图与参考图编辑统一接入

#### 背景与核心改善

火山方舟与 OpenAI 兼容生图虽然都有图片生成接口，但参考图传递、组图数量和模型参数并不相同。本版新增独立的「火山引擎生图」提供商，按方舟 JSON 协议发送文生图、单张参考图编辑、多参考图和受模型能力支持的组图请求，不再套用 OpenAI 的图片编辑上传协议。

- 对接现有 ChatUI 生图会话、`/image` 指令与模型生图工具，无需换一套使用入口；沿用已有代理和密钥管理能力。
- 支持 Seedream 5.0 pro、5.0 lite、4.5、4.0 能力族。每个模型独立选择能力族，手动选择优先；自动模式根据模型 ID 前缀识别，同一提供商下的不同模型互不影响。
- 发起请求前校验尺寸、参考图数量、组图数量和可选参数，遇到不支持的组合直接报错，不静默降级。例如 pro 不支持组图，透明背景与编码格式也受对应模型能力限制。
- 组图数量按方舟的「最多生成张数」语义处理，不保证一定返回指定数量。部分图片失败时保留成功图片，同时记录失败说明。
- 响应图片按实际内容识别格式并检查可解码性，避免将 JPEG 误标为 PNG；接口错误保留可读说明，生成请求失败不自动重试，减少重复提交收费请求的风险。

#### 使用方式

1. 打开「服务提供商 → 生图」，新增提供商时选择「火山引擎生图」，填入方舟 API Key。
2. 在该提供商下添加模型，填写方舟模型 ID 或 Endpoint ID，在模型新增／编辑窗口选择「火山模型能力族」。Endpoint ID 或无法自动识别的模型需手动选择实际能力族。
3. 按需编辑「火山生图参数」，配置尺寸、水印、响应格式等；高级选项通过「修改」入口添加。
4. 在生图会话中切换到该模型，或通过现有生图指令和工具使用。

#### 适用范围与限制

- 本版尚未接入 SSE 流式生图和图层拆分，不支持的参数会明确拒绝。
- 能力族只认模型自身配置，旧提供商源中的同名设置不再生效；使用 Endpoint ID 的模型请检查模型编辑窗口中的能力族。
- 火山类型使用专用「火山生图参数」，不接受通过通用自定义请求体绕过能力校验。

### 2. 生图提供商支持「从对话模型复制」，免去重复填写地址与密钥

#### 核心改善

同一家服务同时提供对话和生图接口时，现在可以直接复用已有对话提供商的连接信息，不必逐项重抄 API 地址和密钥。

- 生图标签的「新增」菜单末尾增加「从对话模型复制」。选择已有对话提供商，再选择目标生图类型，点击「复制并保存」即可创建并自动保存。
- 即使对话提供商下尚未配置模型，也可作为复制来源；新提供商名称自动去重。
- 只复制连接信息，生图协议、超时及专用参数取所选生图模板默认值，不把对话参数混入生图配置。
- 新旧提供商完全独立，后续编辑不会相互修改；缺失的连接字段保持缺失，不用模板地址掩盖。

#### 异常处理

保存失败会显示错误，并保留新配置供编辑重试，不提示成功；重复点击确认不会重复创建提供商。复制连接信息不代表目标服务一定支持所选生图协议，仍需添加对应模型并检查配置。

## ✨ 体验优化（1项）

### 1. 模型引用管理新增类型与状态筛选，快速找出失效引用

#### 背景与核心改善

扫描结果较多时，仅靠关键词和来源筛选仍需逐条寻找异常。本版在原有「来源」筛选旁新增「模型类型」与「状态」下拉框。

- 模型类型按扫描结果动态生成，只显示实际出现的类型；对话和 Agent 执行器排在前面。
- 状态支持正常、已失效、未配置，与表格状态列使用同一判定口径。
- 来源、类型、状态和关键词可叠加使用，并与原有批量模式配合。

#### 使用方式

打开「模型引用管理」并开始扫描后，选择「状态＝已失效」即可集中查看无效引用；也可以组合「来源＝插件」「类型＝Agent 执行器」，专门检查插件中的执行器配置。

## 🛠️ 问题修复（1项）

### 1. 生图测试不再只检查模型列表，真实图片校验与测试日志同步完善

#### 问题现象

此前生图模型测试只获取模型列表，即使真正的图片生成接口不可用，也可能显示测试成功。同时，对话测试没有输出实际回复，生图模型元数据可能为空，增加了定位错误模型和错误配置的难度。

#### 核心改善

- 生图测试改为调用当前模型生成「请生成一只猫。」，请求一张图，使用提供商配置的超时时间。
- 返回内容必须通过图片结构检查和像素解码检查，并保存到临时目录；日志给出图片完整路径，便于打开查看。非图片内容或损坏图片不能通过测试。
- 对话测试记录实际回复正文及存在的思考内容；生图接口返回修订提示词时，将其作为模型回复记录。
- 生图模型名称直接读取当前配置，测试结果与实际请求使用同一模型名称，配置修改后不保留旧的模型名副本。
- 测试日志区分「提供商」「模型ID」「模型」；缺失值显示「未知」，方便定位具体实例。

#### 注意事项

生图测试现在会产生真实生图调用，可能消耗额度或产生费用。图片校验只能确认返回的是有效图片，不能自动判断画面是否符合提示词，也不能证明渠道没有返回固定图片；需要时请打开日志中的图片路径检查。测试图片由临时文件清理机制回收。
