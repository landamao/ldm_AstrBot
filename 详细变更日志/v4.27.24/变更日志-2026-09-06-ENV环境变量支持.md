# 新增：.env 环境变量文件支持（自动生成示例）

- 日期：2026-09-06

## 背景

此前所有 LDMBOT_* 环境变量只能写进系统环境变量或作为启动命令前缀（`LDMBOT_DASHBOARD_PORT=8080 python main.py`），对 Windows 计划任务、服务、桌面快捷方式等启动方式不友好，也没有一个集中位置能看到全部可用变量。main.py `--help` 里虽维护了完整清单，但每次都要翻帮助文本手抄。

## 改动

### 1. 新模块 `astrbot/utils/env_file.py`

- `bootstrap_env(project_root)`：加载 `<项目根>/.env`；文件不存在时先自动写入一份示例模板再加载（生成的提示语：`已生成环境变量示例文件: ...`）；
- 模板为 `(变量=<占位值>, 说明)` 数据驱动，按分节渲染，说明文字用 `unicodedata.east_asian_width` 按 CJK 显示宽度（全角 2 列）对齐；全部处于注释状态，取消行首 `# ` 才生效；
- 覆盖 main.py `--help` 清单的全部 42 个变量（含 `https_proxy`/`http_proxy`），后续新增环境变量时模板与 `--help` 两处需同步维护；
- 加载用 python-dotenv（requirements.txt 已固定 `python-dotenv==1.2.2`，此前声明但未使用），调用参数 `override=False`：已存在的真实环境变量优先于 .env，.env 只作默认值；
- 模板提示路径写成正斜杠形式（如 `D:/ldmbot/data`），避免 dotenv 解析双引号值时把反斜杠当转义处理。

### 2. 加载时机（main.py）

`bootstrap_env` 在 main.py 顶部（`import os` 之后、其余逻辑之前）执行，必须早于：

- 启动横幅（`_should_show_startup_banner` 读 `LDMBOT_NO_BANNER`）；
- `astrbot.core` 导入（`core/__init__.py` 在导入期就读 `LDMBOT_DATA_DIR`、`LDMBOT_DEMO_MODE`、`LDMBOT_NO_PLUGINS` 并创建 data 目录）。

因此模块放在 `astrbot/utils/` 而不是 `astrbot/core/utils/`：import 子模块会先执行父包 `__init__`，`astrbot/core/__init__.py` 是重初始化（建库、读配置），反过来会先于 .env 读取环境变量；`astrbot/utils/__init__.py` 为空包，导入零副作用。

### 3. CLI 路径（astrbot/cli/commands/cmd_run.py）

`run` 命令在 `check_astrbot_root` 通过后调用 `bootstrap_env(astrbot_root)`，CLI 启动与 main.py 行为一致；CLI 自身显式设置的环境变量（`LDMBOT_ROOT`、`LDMBOT_DASHBOARD_PORT`、`LDMBOT_RELOAD` 等）在加载之后赋值，仍然覆盖 .env。

### 4. 帮助文本（main.py --help）

「环境变量」一节开头补充 .env 说明：文件位置、自动生成行为、启用方式（去行首 `# `）、优先级。

## 优先级链

CLI 参数（如 `--data-dir`，`_apply_startup_env_flags` 在 .env 加载后写入 `os.environ`）> 系统环境变量 > `.env` 文件

## 兼容性

- 已存在的 .env 永不覆盖、不改写；
- 写入失败（只读目录、打包 Desktop 运行时等场景）仅打印警告，不影响启动；
- 真实环境变量不受影响（`override=False`），已有部署升级后行为不变。

## 验证

一次性脚本在临时目录覆盖以下场景，全部通过：

1. 导入 `astrbot.utils.env_file` 不触发 `astrbot.core`；
2. 缺失 .env 时自动生成；已存在时不覆盖（追加内容保留）；
3. 模板包含全部 42 个变量且均为注释态、分节对齐正确；
4. 取消注释的变量正确加载进 `os.environ`；
5. 真实环境变量优先于 .env 值（`override=False`）；
6. `main.py --help` 正常渲染新说明，并真实生成项目根 .env；
7. `py_compile` main.py / cmd_run.py / env_file.py 通过。
