# [2026-09-05] 平台日志白色遮罩根修：独立透明度只作用黑色日志区、页面底全透、控件区小块底色

> 本文件为独立变更日志，记录平台日志页透明度体系的完整根修：
> ①「面板透明度」滑块改名为「背景透明度」，只作用于黑色日志终端区，不再连动上方区域；
> ② 日志页页面底整层取消，壁纸直接可见，标题栏与筛选控件行各留一个跟随全局板块透明度的小块底色；
> ③ 定位并记录「白色遮罩感」的最终根因：壁纸透明度 <100 时壁纸与页面白底混合掺白，与日志页本身无关。

---

## 一、问题现象（用户三轮反馈）

- **第一轮**：日志页「面板透明度」滑块拖动时，上方标题、按钮区跟着一起变透明/不透明，且整页像有一层白色遮罩；
- **第二轮**：整页统一方案下线后仍觉得有白色遮罩——黑色日志区调到半透明，透出来的是白雾而不是壁纸；
- **第三轮**：同一份设置，ZCode 内嵌浏览器里清晰、自己浏览器里发白，以为两个浏览器渲染不一致。

## 二、根因（三层叠加）

1. **整页套透明（历史遗留）**：2026-08-19 的「统一透明度」改动把 `.console-page` 整页（含上方区域）套了 `rgba(var(--v-theme-surface), var(--console-alpha))`，浅色主题下 surface 接近白色，半透明时就是「白色遮罩」，且滑块连上方区域一起变。
2. **页面底白层垫在黑区下面**：日志页的 `.page-wrapper` 吃全局板块透明度规则 `rgba(containerBg, --panel-alpha)`，浅色主题下是半透明白，垫在整页最底下——黑色日志区也在它上面，日志区调到半透明时透出的是这层白，不是壁纸。页面底不拿掉，黑区透明度怎么做都隔着白。
3. **壁纸透明度掺白（最终根因，全局性质）**：壁纸层以 `opacity` 实现淡化，底下垫着 `.v-application` 的纯白背景。壁纸透明度 50% 时，所有半透明区域透出的都是「50% 壁纸 + 50% 白」的掺白壁纸——日志区透出面积大、黑底对比强，白感尤其明显。浏览器对照实验证实：壁纸透明度 100（全彩）时日志区调透直接看到真壁纸，白感消失。

第三层解释了「两个浏览器不一样」的误会：内嵌浏览器里是对照实验临时把 `--wallpaper-opacity` 置 1 的状态，用户浏览器里还是 50%。

## 三、设计定式（与用户确认，后续透明度改动沿用）

- 独立透明度滑块**只作用于黑色日志终端区**；页面其他区域跟随全局板块透明度或完全透明；
- 日志页**页面底整层透明**直接露壁纸，不留任何半透明白垫层；
- 标题栏（`.console-header`）与筛选控件行（`.filter-controls`）各保留**一个跟随全局板块透明度的圆角小块底色**（与卡片同款半透明），保证亮壁纸上文字可读——用户在「完全透明」与「控件区留小块底色」两方案中选了后者；
- **不要毛玻璃**：曾实现 `backdrop-filter` 模糊方案（黑罩 + 背景模糊），用户明确否决，已撤销；
- 壁纸建议保持透明度 100 全彩显示，靠黑区自身 alpha 控制透出程度。

## 四、实现

### wallpaper.scss（日志终端区规则重写）

- 删除 `.v-main .console-page` 的整页 `rgba(surface, --console-alpha)` 规则与 `.page-wrapper` 的旧 `:has()` 特判，新增 `.v-main:has(.console-page) .page-wrapper { background: transparent !important }`（页面底全透）；
- `.console-term` 保留 `rgba(30,30,30, var(--console-alpha, 1))` 固定深色半透明（底色不用 `--v-theme-surface`：浅色主题下是白色，深浅主题一致可读）；
- 新增控件区小块底色规则：`.console-page .console-header` 与 `.console-displayer-wrapper .filter-controls` 用 `rgba(var(--v-theme-containerBg), var(--panel-alpha, 1))` + `border-radius: 8px`；
- `.console-displayer-wrapper` / `#console-wrapper` 保持透明（避免与 term 双层叠加）；全屏规则不变（wrapper 全屏深色一层、term 透出）。

### 组件布局配套

- `ConsolePage.vue`：`.console-header` 加 `padding: 12px 16px`（壁纸模式下有色块时不贴文字，非壁纸模式下只是留白）；`.console-display` 高度 `calc(100vh - 190px)` → `calc(100vh - 214px)` 补偿 header 增高；
- `ConsoleDisplayer.vue`：`.filter-controls` 加 `padding: 8px 12px`；`.console-term` 由 `height: 100%` 改为 `flex: 1 1 0; min-height: 0`（wrapper 是 flex column，控件行增高后 `height:100%` 会把终端底部挤出容器）。

### 文案

- `zh-CN/features/console.json` `panelOpacity`：按钮「面板透明度」→「背景透明度」，标签→「日志背景透明度」，hint→「仅调节日志黑色背景，页面其他区域跟随全局板块透明度」。

## 验证

- 浏览器对照实验（内嵌浏览器临时改 CSS 变量）：壁纸透明度 50% → 日志区 50% 透出灰白；壁纸 100% → 同样 50% 透明透出真壁纸、无白雾，确证第三层根因；
- `getComputedStyle` 逐层检查：`.v-application`（白，被壁纸盖住）、`.page-wrapper` / `.console-page` / `.v-main`（全透）、`.console-term`（`rgba(30,30,30,0.57)`，滑块实时联动）符合设计；
- `corepack pnpm build` 构建通过，产物 CSS 中 `--console-alpha` 仅出现在 `.console-term` 与全屏规则。

## 部署 / 回归验证点

- 刷新页面（index.html 为一年期 immutable 缓存，需 Ctrl+F5 强刷一次）；
- 拖动日志页「背景透明度」滑块：只有黑色终端区变化，上方标题/按钮/筛选行不动；
