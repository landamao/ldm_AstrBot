# [2026-09-05] 外观设置透明度存储修复：板块透明度低于 50 保存后变 0、壁纸透明度最高只能存 50

> 本文件为独立变更日志，记录外观设置两个透明度滑块「保存后数值跳变」的修复：
> ① 板块透明度滑到 50 以下（想让板块更实），保存重开直接变 0（板块彻底不透明）；
> ② 壁纸透明度想调到 50 以上（壁纸更实），一直存不进去、上限被锁在 50。
> 两个现象同根源：`normalizeWallpaper` 的 clamp 范围把「默认值常量」误传到了 min/max 位置。

---

## 一、问题现象

- **板块透明度低于 50 直接变 0**：外观设置「板块透明度」滑块（设计范围 0-90，0=完全不透明）拖到 50 以下保存，重新打开设置页滑块显示 0，板块变成完全不透明——且稳定复现，50 是明显的分界线；
- **壁纸透明度调不实**：「壁纸透明度」滑块（设计范围 10-100，100=完全不透明）拖到 50 以上，保存重开回落到 50，壁纸永远调不到比默认更实。

## 二、根因（两处错误叠加成「低于某个值直接变 0」）

### 1. `normalizeWallpaper` clamp 参数错位

`clampNumber(value, fallback, min, max)` 的调用把默认值常量传到了 min/max 位置：

- 板块透明度：`clampNumber(value, PANEL_OPACITY_DEFAULT, PANEL_OPACITY_DEFAULT, 90)` —— **min=50**，低于 50 的值保存时全被拉回 50；
- 壁纸透明度：`clampNumber(value, WALLPAPER_OPACITY_DEFAULT, 10, WALLPAPER_OPACITY_DEFAULT)` —— **max=50**，高于 50 的值全被压回 50。

### 2. 「默认值省略存储」与「缺字段兜底 0」不匹配，把拉回放大成变 0

`normalizeWallpaper` 的存储约定是**等于默认值的字段省略不写**（板块透明度默认 50 → 落盘对象里没有 `panelOpacity` 字段）。而设置页加载时用的是写死的兜底：

```js
wallpaperOpacity.value = wp.opacity ?? 100;
panelOpacity.value = wp.panelOpacity ?? 0;   // 缺字段 → 0 = 完全不透明
windowBlur.value = wp.windowBlur ?? 20;
```

完整故障链：拖到 50 以下 → clamp 拉回 50 → 恰好等于默认值、字段省略 → 落盘对象缺 `panelOpacity` → 重新加载时 `?? 0` → 滑块显示 0、板块完全不透明。拖到恰好 50 也走同一条链。「低于某个值直接变成 0」即由此而来。

## 三、实现

### `uiPreferenceSync.js` clamp 范围恢复设计值

- 壁纸透明度：`clampNumber(value, WALLPAPER_OPACITY_DEFAULT, 10, 100)`；
- 板块透明度：`clampNumber(value, PANEL_OPACITY_DEFAULT, 0, 90)`，并留注释说明 min 误传默认值的后果链，防止回归。

### `Settings.vue` 加载兜底改用默认值常量

```js
wallpaperOpacity.value = wp.opacity ?? WALLPAPER_OPACITY_DEFAULT;
panelOpacity.value = wp.panelOpacity ?? PANEL_OPACITY_DEFAULT;
windowBlur.value = wp.windowBlur ?? WINDOW_BLUR_DEFAULT;
```

与「默认值省略存储」约定对齐：缺字段 = 默认值，而不是 0/100/20 的巧合值。`wallpaperApplier.js` 的兜底本就用常量，未动。

| `dashboard/src/views/Settings.vue` | 加载壁纸设置时的三个 `??` 兜底改为默认值常量，附注释 |

## 验证

- 钳制逻辑 node 逐值验证：板块 30→30、0→0、50→50、95→90；壁纸 100→100、30→30——全部落在设计范围，默认值 50 行为不变；
- 历史脏数据自愈：此前被错误钳制存坏的配置（缺字段或值被拉回 50），修复后重新保存任意值即写入正确字段；缺字段场景按默认 50 读取，不再跳 0。

## 部署 / 回归验证点

- 刷新页面后进外观设置：板块透明度拖到任意值（含 0 和 90）保存重开，数值保持不变；壁纸透明度同理（10-100 全范围）；
- 板块透明度调低后各页面卡片/侧边栏/顶栏实际透明度随之变化，无跳变；
- 不动设置直接刷新：默认配置（无壁纸偏好或全默认）下滑块显示 50，板块半透明，不再出现 0。

## 回滚

还原上表 2 个前端文件并重新构建。回滚后「低于 50 变 0」「壁纸最高 50」行为复现（已存坏的值不会因回滚自动变坏，需重新拖动才会触发）。
