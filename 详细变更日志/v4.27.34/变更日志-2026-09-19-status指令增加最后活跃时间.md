# [2026-09-19] /status 回执新增「最后活跃时间」

> 本文件为独立变更日志，记录 2026-09-19 一次状态指令信息增强：
> `/status` 回执在「对话 ID」之后新增一行「最后活跃时间」，取自对话的
> `updated_at`，与 `/ls` 列表里的「上次更新」同一数据来源。

---

## 背景

`/status` 回执包含会话 ID、对话 ID、Agent 状态、上下文占用、历史轮数与
累计消耗，但没有「这个对话最近什么时候活跃过」。跨会话查看
（`/status <会话>`）或翻旧对话时，无法从回执判断对话是刚才还在聊，
还是早已沉寂。

## 改动内容

- `astrbot/builtin_stars/builtin_commands/commands/conversation.py` 的
  `status`：取目标会话当前对话的 `updated_at`（conversations 表行每次
  更新对话内容/标题/人格等由 SQLAlchemy `onupdate` 自动刷新的秒级
  Unix 时间戳），按本地时区格式化为 `%m-%d %H:%M`（与 `/ls` 的
  「上次更新」同款格式），插入回执「对话 ID」与「Agent 状态」之间；
- `updated_at` 缺失或为 0 时显示「未知」；
- 跨会话 `/status <目标>` 同样显示目标对话的最后活跃时间；
- 目标会话没有当前对话的分支不显示该行（无对话可谈活跃）。

## 回执示例

```
会话 ID: aiocqhttp:GroupMessage:123456
对话 ID: 3fa2b1c8...
最后活跃时间: 09-19 14:30
Agent 状态: 否
当前上下文: 12.3k（模型返回）
历史消息轮数: 5
累计消耗:
  总计:     45.6k
  输入:     40.1k
  输入缓存: 3.2k
  输出:     2.3k
```

## 验证

- `tests/test_cross_session_commands.py` 新增 2 个回归：
  - `updated_at` 有值时回执含「最后活跃时间: MM-DD HH:MM」格式行
    （断言用正则匹配，不绑死时区）；
  - `updated_at` 为 0 时显示「未知」；
- 共享 fake（`test_compact_command.py::_context`）的对话实体补上
  `updated_at=0` 字段，既有 status/compact 回归不受影响；
- 全量 `pytest tests/ -q`：317 过 1 失败（生图测试既有问题，与本改动无关）。

## 部署/使用注意

- 纯 py 改动，需手动同步源码并重启 ldm 生效；
- 「最后活跃时间」反映的是对话内容/标题/人格等落库更新时刻；只发指令
  不触发 LLM 或更新对话的操作不会刷新它。
