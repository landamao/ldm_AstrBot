# [2026-09-19] 壁纸透明度移除与板块透明度重设计：壁纸始终完全显示、板块透明度只作用于板块、页面大块容器保留一层底、ChatUI 气泡化

> 本文件为独立变更日志，记录 2026-09-19 一次壁纸/板块透明度体系重设计（经用户
> 四轮反馈定案）：移除「壁纸透明度」滑块（壁纸始终完全显示）、「界面板块透明度」
> 只作用于板块且页面大块底层容器保留一层底布、ChatUI 页面底透明+消息气泡半透明
> 化、板块透明度上限 90→100。

---

## 需求背景（用户四轮反馈定案）

1. **第一轮**：壁纸有些不好，去掉「壁纸透明度」调节；「界面板块透明度」应该只
   应用于板块部分，而不是整个页面都盖上一层白布（当时平台日志页已有不盖白布的
   特例）；板块透明度最大值不要是 90，100% 也可以。
2. **第二轮**：有些地方透明度很好，有些地方仍有一大块白布；模型提供商页、管理
   行为页（插件页）中间叠加很多层白布；很多页面有一个「很大块」的容器；ChatUI
   完全还是白布，bot 消息文字没有小块承载，透明则文字看不清、不透明则看不到壁纸。
3. **第三轮**：数据统计页全白（第二轮改动的回归）；页面大块底层容器不能全撤，
   文字裸露在壁纸上面更不好看清，这些大块保留一层还是有必要的。
4. **第四轮（最终定案）**：之前撤销的页面大块底层容器全部加回来，**只加一层**，
   和上面的板块正常叠加，让文字看清即可。

## 根因

### 叠层白布（第二轮）

- 旧 wallpaper.scss 给提供商页骨架每一层（provider-page → workbench → main →
  config-shell → body → section，共五六层）、配置页行容器每一层（config-section /
  config-item 等）都上 `rgba(surface, --panel-alpha)`，N 层 50% 半透明白叠加后
  等效 95%+ 不透明，等于实心白布；
- 旧规则的排除彩色底用 `:not()` 链（优先级 (0,11,0)）+ `!important`，把代码里
  内联声明 `background-color: transparent` 的容器（插件页外层 v-card）也强行涂色；
- 表格从根元素到 td 每层都上色（卡片+表格根+table+tbody+tr+td 最多六层）。

### 数据统计页全白（第三轮回归）

- StatsPage.vue 自带不透明底色 `--stats-bg: rgb(var(--v-theme-background))`，
  一直靠壁纸 paint 规则（`!important`）盖成半透明；第二轮把 `.stats-page` 移出
  着色名单后，自身不透明底露出 → 整页全白。

### ChatUI 整页白布（第二轮）

- `.chat-ui` 用 `--chat-page-bg`（浅色固定 253,252,252 / 深色跟随主题 background，
  alpha 跟随 ChatUI 面板透明度）铺满整页；bot 消息气泡 `.message-bubble.bot` 背景
  是 transparent，文字全靠整页布承载——布透明文字就没地方落。

## 修复内容

### 壁纸透明度移除（第一轮）

- 前端 `normalizeWallpaper`（uiPreferenceSync.js）不再读取/下发 `opacity`，
  `WALLPAPER_OPACITY_DEFAULT` 删除；旧存量配置里的 `opacity` 字段读取时直接丢弃，
  下次保存自然清除，无需迁移；
- `wallpaperApplier.js` 不再写 `--wallpaper-opacity`；wallpaper.scss 壁纸层
  `::before` 去掉 opacity，壁纸始终完全显示；
- Settings.vue 删除滑块、状态、预览 opacity；i18n 删除 `opacityLabel`/`opacitySuffix`；
- 后端 `dashboard_preference_service.py` 的 `normalize_wallpaper` 同步移除 opacity
  规范化与 `WALLPAPER_OPACITY_*` 常量。

### 板块透明度体系（最终格局）

- **整页 page-wrapper**：`html.wallpaper-active` 时透明（wallpaper-active 类由
  wallpaperApplier.js 按当前方向是否实际显示壁纸开关），壁纸从板块空隙透出；
  无壁纸时不挂类，保持原 containerBg 观感；
- **页面大块底层容器各保留一层** `rgba(surface, --panel-alpha)`（跟随滑块）：
  `stats-page`、`trace-page`、`plugin-detail-page`、`kb-detail-page`、`config-panel`
  （配置页）、`provider-page`（提供商页）；
- **dashboard-page 组**（模型引用/定时任务/子代理/追踪）：靠自身 CSS 的
  `rgba(background, --panel-alpha)` 一层，wallpaper.scss 不再强制透明；
- **大块内层骨架/行容器透明防叠加**：provider-workbench/main/config-shell/body/
  header、provider-sources-panel/list/empty、provider-source-item、config-item 等；
- **表格去重**：表格内部元素（table/thead/tbody/tr/td/th、v-data-table__td/__th）
  一律透明，底色只由 `.v-table`/`.v-data-table` 根一层承担；已上色卡片内的表格根
  也透明（`.v-main :is(.v-card,.v-sheet) :is(.v-table,.v-data-table)`）；行悬停
  高亮走 Vuetify 的 td::after 覆盖层，不受影响（项目内无 fixed-header 表格）；
- **内联透明尊重**：`.v-main [style*="background-color: transparent"]`（含四种
  写法变体）强制透明，插件页外层 v-card 等代码明确声明透明的容器不再被涂色；
- **着色规则降优先级**：排除彩色品牌底改用 `:where(:not(...))`，paint 规则优先级
  从 (0,11,0) 降到 (0,4,0)，供上述去重/透明规则覆盖；已核对全库
  `background + !important` 规则（Settings system-config-group、ConfigPage 未保存
  横幅等，均 (0,3,0) 以下）无被放出的回归。

### ChatUI 气泡化（第二轮）

- 壁纸激活时 `.chat-ui` 与输入区衬底 `.conversation-stack:not(.is-empty)
  .composer-shell::before` 透明，直接露壁纸；
- 原整页底色 `--chat-page-bg` 移到消息气泡上：bot 气泡直接使用（浅色
  253,252,252 / 深色跟随主题 background，透明度跟随 ChatUI 面板透明度
  `--chat-alpha` → 全局 `--panel-alpha`）并补回 `padding-left: 14px` 让底色不贴
  文字；用户气泡用同款底色 + `linear-gradient` 叠加原有 primary 12% 染色；
- 侧边栏/输入条本就跟随同一透明度变量，自动成为半透明板块；无壁纸（未挂
  wallpaper-active）时保持原样。

### 板块透明度上限 90 → 100（第一轮）

- 前端 `normalizeWallpaper` clamp、Settings 滑块 `:max`、ChatUI 面板透明度滑块
  与三处 `Math.min(90, ...)` clamp、后端 `PANEL_OPACITY_MAX` 同步放开到 100。
