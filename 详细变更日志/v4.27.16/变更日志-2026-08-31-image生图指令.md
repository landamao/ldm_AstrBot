# [2026-08-31] 聊天侧 /image 生图指令与任务管理

> 本文件为独立变更日志，记录 2026-08-31 新增聊天侧 `/image` 生图指令：异步生图返回任务ID、停止任务、列模型/列任务、普通用户单任务限制与冷却；配置落在内置指令插件 `_conf_schema.json` 的「生图设置」分组。顺带修复默认生图模型改配置后不生效（读启动缓存）。

---

## 问题现象

- 聊天侧没有独立生图指令，只能走 LLM 工具或 WebUI ChatUI 生图会话。
- WebUI 改了「默认生图模型」后，聊天侧/工具仍用启动时选中的那个，不重启不跟着变。

## 背景原因

- `Context.get_using_image_generation_provider()` 和 ChatUI 生图会话读的是 `provider_manager.provider_settings` / `curr_image_generation_provider_inst`，这是启动时从配置拷出来的引用快照，保存配置不会刷新这份缓存。

## 改动内容

### 新增：`/image` 指令组

- `/image star <提示词>` / `/image start <提示词>`：用默认生图模型异步生图，立刻返回任务ID，完成后把图发回原会话。
- `/image model <模型ID> <提示词>`：指定模型生图。
- `/image stop <任务ID>`：停止任务。普通用户只能停自己的，管理员可停所有人的。
- `/image mlist`：列出可用生图模型（字段分行，标「模型ID」）。
- `/image tlist`：列出自己正在进行的任务（提示词超过 20 字用省略号）。
- `/image tlist <用户ID>` / `/image tlist all`：管理员查看指定用户 / 全部任务。
- `/image help` 或未知子指令（`*` 兜底）：发送帮助。
- 仅输入 `/image`：不特判美化帮助，走框架默认指令树（与其它指令组一致）。

帮助文案对齐 `/plugin`：标题 + 开头一次「用法：」，后面每条指令单独成行，不再每条都写「使用方法：」。

缺参提示仍以「使用方法：」开头，避免回执以 `/` 起头触发其它机器人。

### 新增：插件配置「生图设置」

落在 `astrbot/builtin_stars/builtin_commands/_conf_schema.json`，object 分组（写法对齐复读器插件）：

- **生图单任务限制**（bool，默认 true）：普通用户同时只允许一个进行中任务。配置缺失按开启处理。管理员不受限。
- **生图冷却时间**（int 滑块 0–300 秒，默认 0）：与单任务限制配对。开启时在任务结束（成功 / 失败 / 停止）后再计时；关闭时在任务开始时计时。0 表示无冷却。管理员不受限。

不影响 LLM 生图工具和 ChatUI 生图会话。

### 修复：默认生图模型改配置后立即生效

- `Context.get_using_image_generation_provider()` 改为每次从 `get_config()["provider_settings"]` 读当前 `default_image_generation_provider_id`，不再读启动时缓存。
- ChatUI 生图会话未指定模型时同样走这条路径。

## 使用方式

```
/image star 一只猫
/image start 一只猫
/image model seedream 一只猫
/image stop abcd1234
/image mlist
/image tlist
/image tlist all
/image help
```

配置入口：WebUI → 插件「builtin_commands」→「生图设置」。
