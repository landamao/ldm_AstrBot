# [2026-08-31] 续流完成后空 bot 消息、生图会话禁止指令

> 本文件为独立变更日志，记录 2026-08-31 WebUI ChatUI：离开页面再回来续流完成后多出一条空 bot 消息；生图会话不应弹出/使用指令建议。

---

## 问题现象

- 普通聊天会话生成中途离开，再回来续流。回复完成后，正文下面会多出一条空的 bot 消息（只有头像、时间和操作按钮，没有文字）。
- 生图会话输入 `/` 仍会弹出指令建议，可以选指令发出去。生图会话不应使用指令。

## 背景原因

### 空 bot 消息

WebChat 流式落库会在 `complete` 时把正文 insert 成一条 bot。流结束时 `end` 往往只剩 `agent_stats`（token 用量）。旧逻辑把「有 agent_stats」也当成要落库，于是再 insert 一条没有正文的空 bot。离开再进来时，历史里就会看到正文 + 空消息叠在一起。

续流前端也会在已有 bot 旁边再插一条 `active-run-*` 占位。checkpoint 对不上或快照为空时，占位会一直留着。

### 生图会话指令

`ChatInput` 挂载时无条件拉指令列表。输入以唤醒前缀开头就弹出 `CommandSuggestion`。生图会话没有关掉这条路径。

## 改动内容

### 空 bot：只剩用量统计时合并进上一条，不再新建

- `complete` 已落库正文后，`end` 只剩 `agent_stats` 时改为 update 上一条 bot，不再 insert。
- 没有上一条可见 bot 时，纯用量统计不落库。
- SSE（`chat_service`）、Live Chat WS、Open API WS 三条落库路径一起改。
- 前端加载历史时丢掉空 bot；续流优先接到已有同 checkpoint 的 bot 上，不再多插占位。
- 消息列表对空 bot 行不显示。

### 生图会话禁止指令

- 生图会话不拉指令列表、不弹出指令建议。
- 输入 `/` 也不会出候选。
- 切回普通聊天会话再拉指令列表。
