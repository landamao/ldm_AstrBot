# [2026-09-13] 模型引用管理页面：统一扫描/替换各处配置引用的模型

> 本文件为独立变更日志，记录 2026-09-13 新增的「模型引用管理」页面（v4.27.27）：
> 一键扫描主配置（含全部 abconf 配置档案）与插件配置中所有模型选择项及对模型 ID 的引用，
> 行内弹窗改模型、批量同类型替换/清除，模型失效时不再逐个配置页去找。

---

## 问题现象

1. 模型的使用配置散落各处：主配置的对话模型链、图片转述、生图、STT/TTS、上下文压缩、
   群聊图片转述，各插件的配置文件里也各有模型选择。某个模型崩溃/失效后，要到处找
   包含模型提供商选择的配置逐个修改，效率极低；
2. 部分插件配置没有模型选择标记，引用了已失效的模型 ID 更难被发现
   （实测「地狱审判」插件引用的 `ldm-api/doubao/seed-2-0-code` 已不存在）。

## 方案设计

- 后端新增扫描/批量修改服务与 REST 端点，扫描只认配置内存对象（不落盘、不改配置）；
- 识别方式双轨：优先按配置 schema 的 `_special` 模型选择标记（与前端渲染分支一致），
  插件无标记时按「string/list 值恰好命中某个提供商 ID」做「疑似引用」兜底；
- 批量语义为「直接写入目标值」（不做 from→to 模式匹配），同一插件/配置档案的
  多条修改合并为一次落盘，插件自动热重载、主配置即时生效。

## 实现内容

### 后端（`model_usage_service.py` / `model_usages.py`）

- 新增 `ModelUsageService`，端点：`GET /api/v1/model-usages/scan`、
  `POST /api/v1/model-usages/apply`（scope=config）；
- 扫描范围：
  - 主配置按 `CONFIG_METADATA_3` 的 `_special` 标记识别（`select_provider*`、
    `select_chat_model_chain`、`select_agent_runner_provider:*`），覆盖 default
    与全部 abconf 配置档案；「对话模型链」把主模型 + 回退列表合并为一条目展示
    （`fallback_chat_models` 隐藏条目不再单列）；
  - 插件配置遍历 `star_registry` 各插件 schema（含嵌套 object 二层及更深，
    key_path 带层级前缀），下发来源信息：插件名/显示名/是否内置/是否激活、
    配置档案名、键名路径、显示名、提示、提供商类型、识别方式（标记/疑似引用）、
    当前值、命中与失效的模型 ID；
- apply 语义：请求每项带 `new_value` 字符串列表直接写入——单值项取首元素
  （空列表=清空），列表项整体替换，模型链第一项写主模型、其余写回退列表
  （自动维护「回退列表不含主模型」语义）；同值报 unchanged 不落盘；
  失效 ID 允许写回（故意保留引用的场景），由扫描界面持续标红提示；
- 落盘回调：插件 `save_config()` 后 `plugin_manager.reload()` 热重载，
  主配置 `save_config()` 后 `reload_pipeline_scheduler()` 即时生效；
  同一目标的多条替换只落盘/重载一次。

### 前端（`ModelUsagePage.vue` 等）

- 新路由 `/model-usages`，入口在侧边栏「更多功能」→「模型引用管理」；
  懒加载：进入页面不自动扫描，点击「开始扫描」才拉取（页面文案说明不修改配置）；
- 表格列：来源（主配置档案名+分组 / 插件显示名+插件名+内置/未激活标记）、
  配置项（显示名+键名路径）、类型（对话/生图/语音识别/语音合成/向量/重排/
  Agent 执行器）、状态（正常/已失效/未配置）、模型选择；
- 单行修改：行内嵌 `ProviderSelector`（与插件配置页一致的弹窗，可搜索、
  按提供商类型过滤；模型链/列表行为 multiple 可排序），弹窗确认后立即保存该行；
- 批量模式：点「批量模式」按钮进入，表头复选框全选/全不选（半选态）；
  类型锁定——勾选第一行后锁定该类型，点不同类型的行不勾选并弹红色自动消失
  toast 提示，全选时跳过不同类型行并提示数量；目标模型选择器类型跟随锁定类型；
  「应用替换」把勾选行的模型直接改为目标模型，「清除模型」把勾选行全部设为
  「未选择」；均逐条 toast 具体信息后弹统计；
- toast 分两档：校验类红色提示 3 秒自动消失（`error` + `timeout: 3000,
  closable: false`），真正的操作失败（保存/重载失败）保持带 X 常驻；
- 页面大卡片加 `config-section-card` 类复用全局 Q 弹豁免（按压不整块缩放，
  内部控件各自 Q 弹）；行内选择按钮防挤压截断；
- i18n：新增 `features/model-usage.json`（必须在 `translations.ts` 静态注册，
  否则整页 [MISSING]）+ `core/navigation.json` 增入口键。

## 部署/测试注意

- 后端为新增文件+两处注册，需重启 ldm 生效；前端已进 dist，刷新页面即生效；
- 扫描读取的是运行中配置对象，WebUI 上其它页面改动配置后重新扫描即可看到最新值；
- 失效模型 ID 允许通过 apply 写回（保留引用场景），是否失效以扫描列表的红色
  「已失效」标记为准，不做硬性拦截。
