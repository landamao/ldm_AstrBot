# [2026-09-14] 上下文压缩支持配置保留最近 N 轮对话

> 本文件为独立变更日志，记录 2026-09-14 两次压缩相关改动：
> ① 将 2026-09-13 `/compact [N]` 引入的「保留最近 N 轮」能力接入自动压缩路径，
> WebUI 压缩上下文配置区新增「压缩时保留最近对话轮数」配置项，默认 5；
> ② 压缩触发阈值可配置（新配置 `context_compress_threshold`，默认 0.82），
> 并修复 `/compact` 与自动压缩的两处行为不一致。

---

## 背景

2026-09-13 的 `/compact` 指令为 `LLMSummaryCompressor` 新增了
`keep_recent_rounds: int | None`（保留最近 N 轮原文、更早轮次进摘要），
但仅手动指令可指定；自动压缩路径（`context_limit_reached_strategy = llm_compress`
触发时）仍只能按 `keep_recent_ratio`（token 比例，钳制 0–0.3）保留最近上下文，
WebUI 无法配置轮次粒度的保留策略。

## 改动内容

### 新配置项 `provider_settings.llm_compress_keep_recent_rounds`

- 类型 int，默认 5；大于 0 时压缩保留最近该轮数的对话原文，更早轮次进摘要，
  优先于「压缩时保留最近上下文比例」；0 表示关闭，回退按比例保留。
- 显示条件与压缩提示词 / 保留比例一致：
  `context_limit_reached_strategy = llm_compress` 且 `agent_runner_type = local`。

### 传递链路（配置 → 压缩器）

1. `default.py`：默认值 5 + 配置页 schema 条目；
2. `internal.py`（LLM 请求子阶段）：`settings.get(..., 5)` 读取，并入 `MainAgentBuildConfig`；
3. `astr_main_agent.py`：`MainAgentBuildConfig` 新增字段，`reset()` 时传给 runner；
4. `tool_loop_agent_runner.py`：透传进 `ContextConfig`；
5. `context/config.py`：`ContextConfig` 新增 `llm_compress_keep_recent_rounds: int | None`；
6. `context/manager.py`：构造 `LLMSummaryCompressor` 时传入。

### WebUI

- `dashboard/src/i18n/locales/zh-CN/features/config-metadata.json`
  新增条目（description + hint），并重建 dist、写回两处 version。

### 行为说明

- 自动压缩默认行为变化：此前默认按比例（0.15）保留，现在默认精确保留最近 5 轮；
  想恢复按比例保留，把该配置设为 0。
- 手动 `/compact` 同步对齐（2026-09-14 第二批改动）：
  - 不带 N 时读取「压缩时保留最近对话轮数」配置作为默认（显式指定的 N 仍优先），
    与自动压缩保留策略一致；配置为 0 时保持旧行为（按比例）。
  - 无模型截断回退（`/compact yes`）原读取不存在的 `truncate_turns` 键（固定丢 1 轮），
    改读「轮次超限时一次丢弃轮数」（`dequeue_context_length`）。
  - `/compact yes` 未显式传 N 且配置轮数 > 0 时，同样按「保留最近 N 轮」截断
    （与 LLM 摘要路径对称），不再是逐步丢轮。
- 压缩触发阈值可配置：新增 `provider_settings.context_compress_threshold`
  （float，默认 0.82，滑条 0.5–1.0），上下文 token 达到模型窗口的该比例时触发
  压缩/截断策略；压缩后仍超过该比例时的对半截断判断也使用该值。对
  「按对话轮数截断」与「由 LLM 压缩上下文」两种策略均生效。
- 存量配置缺键由 `settings.get` 默认值兜底，重启后框架自动补键。

## 验证

- `py_compile` 通过全部 7 个 Python 改动文件；
- 链路验证脚本通过：`ContextConfig(keep_recent_rounds=5)` 经 `ContextManager`
  后压缩器 `keep_recent_rounds == 5`；传 0 时压缩器回退 `None`（按比例）；
  6 轮保留 5 轮切分正确（1 轮进摘要）；不足 5 轮时全部保留；
- 阈值链路验证脚本通过：`context_compress_threshold` 传入两种压缩器的
  `compression_threshold`；缺省 0.82；`should_compress` 按自定义阈值判断；
  `/compact` 默认轮数读取逻辑（缺键 5 / 配置 3 / 配置 0 关闭）；
- dashboard 构建成功，dist 产物中含两个新配置项文案。

## 部署注意

- 需重启 ldm 使后端读取新配置生效；WebUI 刷新页面即可看到新配置项；
- 自动压缩默认行为变化（比例 → 最近 5 轮），已有部署若依赖旧行为，
  需手动把「压缩时保留最近对话轮数」设为 0。
