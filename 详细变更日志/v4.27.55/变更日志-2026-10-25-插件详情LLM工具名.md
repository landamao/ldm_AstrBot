# 变更日志 — 2026-10-25 — 插件详情页 LLM 工具名展示

## 背景

WebUI 插件管理详情页的「LLM 工具」分组此前只有两列：名称和描述。名称列取的是 `handler.handler_name`，也就是插件里被 `@llm_tool` 装饰的处理函数名（例如 `llm_tool_edit_note`），而模型实际调用时使用的是 `@llm_tool(name="...")` 指定的工具名（例如 `edit_note`）。两者不一致时，详情页无法直接看出插件向模型暴露了哪些工具。

## 改动

### 1. 核心注册：记录工具名

`astrbot/core/star/register/star_handler.py`：

- `register_llm_tool()` 在创建/获取 handler 元数据后，把本次注册的工具名追加到
  `handler.extras_configs["llm_tool_names"]`。
- 追加前去重，兼容同一函数注册多个工具名、插件重载重复执行装饰器等场景。
- 不改变 `llm_tools.add_func()` 的原有注册与调用逻辑。

### 2. 插件详情接口：返回 `llm_tool_name`

`astrbot/dashboard/services/plugin_service.py`：

- 处理 `EventType.OnCallingFuncToolEvent` 时，从 handler 元数据读取 `llm_tool_names`。
- 多个工具名按注册顺序用 ` / ` 连接，写入组件字段 `llm_tool_name`。
- 未采集到工具名时不写入该字段，保持旧接口兼容。

### 3. WebUI：新增工具名列

`ldmbot-dashboard/src/views/extension/PluginDetailPage.vue`：

- 「LLM 工具」分组保留原第一列（处理函数名），在其后新增工具名列。
- 工具名使用主色高亮的 `code` 样式；悬停/点击 tooltip 显示「LLM 工具名: xxx」。
- 新增列宽 220px，700px 以下收窄到 120px；缺失时显示 `-`。
- 其他分组（页面、技能、指令、监听器、钩子）表格结构不变。

`ldmbot-dashboard/src/i18n/locales/zh-CN/features/extension.json`：

- 新增 `detail.llmToolName` 文案。

### 4. 发版打包脚本

原 `打包2.sh` 已丢失，本版按往期产物格式补回：

- `scripts/release/package_release.py`：生成 5 个 release 附件，并输出镜像用 `latest.zip`。
- `scripts/release/templates/install_embedded.header.sh`：从 4.27.54 内嵌安装脚本抽出的文本头，`ARCHIVE_SIZE` / `EMBEDDED_VERSION` 改为占位符。
- `scripts/release/templates/install_mirror.sh`：非内嵌安装脚本模板。
- 脚本会校验版本一致性、zip 完整性、中文文件名 UTF-8 标志，以及内嵌脚本尾部 zip 是否完整。

## 边界与兼容

- 仅新增展示字段，不改变工具注册、调用、权限、插件配置或工具开关行为。
- 旧版进程内已加载的插件没有 `llm_tool_names` 元数据，重启或重载插件后补齐；在此之前该列显示 `-`。
- 未显式指定 `@llm_tool(name=...)` 时，工具名默认等于函数名，新列会显示相同内容。
- 同一函数通过多个 `@llm_tool` 注册多个工具名时，详情页会合并展示。

- WebUI：`pnpm build`（`vue-tsc --noEmit` + `vite build`）通过，产物写入主仓库 `dashboard/dist/`。
