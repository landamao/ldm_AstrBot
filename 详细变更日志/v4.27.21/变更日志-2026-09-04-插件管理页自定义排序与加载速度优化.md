# 变更日志：插件管理页自定义排序与加载速度优化（2026-09-04）

## 概述

本轮针对 WebUI「插件管理页」做了两大块改动：

1. **插件自定义排序**：新增排序模式（长按拖拽任意排序），置顶改为「直接移到最前」，排序列表服务端持久化（跨浏览器共享），并加内容哈希判断排序是否变化 + 保存中/正在更新的反馈提示。
2. **插件管理页加载速度**：市场数据改为懒加载（进插件管理页不再请求市场）、插件管理页加 KeepAlive 缓存（切页回来不重挂载）、后端市场缓存加 5 分钟 TTL。

## 一、插件自定义排序

### 背景 / 需求

- 原「已安装插件置顶」只存置顶子集、无全局拖动排序；置顶是「置顶/取消置顶」开关。
- 需求：点击排序按钮进入排序模式，长按插件卡片拖到目标位置排序；排序信息存服务端、跨浏览器保持；置顶功能改成「直接排到最前面」。

### 改动

- 顶部新增「排序」按钮，点击进入排序模式；模式内长按卡片拖拽调整（sortablejs，`delayOnTouchOnly` 区分触屏长按 / 桌面按住即拖），「完成」保存、「取消」放弃。
- 排序模式下：卡片右上角显示拖拽手柄，底部操作按钮/开关/置顶临时隐藏；拖起中的卡片半透明（0.55，不遮挡下方），目标落点（`.sortable-ghost`）加 3px 主题色框。
- 「置顶」按钮改为单向「移到最前」（不再 toggle），已安装插件与「插件页面」两处卡片同步改。
- 排序列表服务端持久化：复用既有全局偏好 `dashboard_pinned_plugins`（有序 name 列表）+ `/api/v1/plugins/pinned` 接口，旧置顶列表天然成为「排在最前的插件」，零迁移。
- 内容哈希缓存：后端对排序列表算 sha256，GET 支持 `?hash=` 查询参数，一致时返回 `{unchanged: true, names: null}`，前端据此直接用本地缓存；localStorage 增 `astrbot.pinnedExtensionsHash`。
- 保存反馈：排序「完成」按钮保存时显示「保存中」，置顶触发保存时顶部显示「正在更新排序」chip（去掉原 250ms 防抖 watch，改为显式 `persistOrder` + `isSavingOrder` 跟踪）。

## 二、插件管理页加载速度

### 背景 / 问题现象

- 实测：`/api/v1/plugins`（列表）29ms、`/api/v1/plugins/pinned`（排序）6ms，但 `/api/v1/plugins/market`（市场）**10.2 秒**——1.6MB 市场数据经代理下载。
- 进插件管理页会无条件在 onMounted 拉取市场数据；「从平台日志 / 模型提供商切回」时页面重新挂载，又触发一次。
- 「管理行为 → 插件管理」快，因为两者是同页不同标签（hash 切换不重挂载）；「平台日志 → 插件管理」慢，因为跨路由重挂载。

### 改动

- **市场懒加载**：市场数据只在首次进入「插件市场」标签时才加载（`loadMarketData` + `watch(activeTab)`），进插件管理页不再请求市场；市场页加载时显示进度条。依赖市场的更新检测 / 随机推荐 / 已安装标记随市场一起在懒加载时执行。
- **KeepAlive 缓存**：插件管理页 `<KeepAlive include="ExtensionPage">` 缓存，从别的路由切回不重挂载（列表 / 滚动 / 排序 / 对话框状态都不丢），秒回。
- **后端市场缓存 TTL**：`PLUGIN_MARKET_CACHE_TTL_SECONDS = 5 * 60`，缓存写入后 5 分钟内 `is_cache_valid` 直接判有效、跳过远程 MD5 校验，避免跨会话重复下载 1.6MB。

## 验证

- 后端 `py_compile` 通过；前端 `vue-tsc --noEmit` + `vite build` 通过并部署到 `dashboard/dist`；
- 接口实测：`/api/v1/plugins/market` 首次 10.2s（下载 1.6MB）、二次 57ms（磁盘缓存命中）；
- 产物校验：`sortable-ghost` 目标框、`saveIndex`/`loadMarketData`、`name:"ExtensionPage"` 均已进 bundle；
- 已构建部署 + 同步源码，需手动重启 ldm + Ctrl+F5。

## 部署 / 回归验证点

- 手动重启 ldm 生效；
- 插件管理页进入 / 从其他页切回应秒开（KeepAlive + 市场懒加载）；
- 排序模式：点「排序」→ 长按卡片拖到目标位置（目标位置有框、拖起卡片半透明）→「完成」保存（按钮显示「保存中」），换浏览器登录后顺序一致；
- 置顶按钮：点击把插件移到最前；
- 插件市场：首次点进「市场」标签才加载（显示进度条），之后秒出；
- 已安装插件的「有更新」角标需首次打开过市场标签后才显示（依赖市场数据比对版本）。
