# [2026-10-07] 空艾特去特殊化：删除 60 秒等待逻辑，空唤醒在管线内补提示词正常走 LLM

> 本文件为独立变更日志，记录空艾特（仅 @ 机器人）与仅唤醒前缀消息的去特殊化改造。

---

## 问题现象

1. 开启群聊上下文增强后，空艾特期望能联系群聊上下文回复，但原逻辑绕开正常管线直接 `request_llm`（`contexts=[]`、`system_prompt=""`），群聊上下文的前置注入（on_llm_request）不生效。
2. 空艾特走独立逻辑：先直接请求 LLM 回复一句，再开 60 秒 `session_waiter` 等待该用户下一条消息，拼上 @ 组件后重新投递事件队列。该逻辑与「只 @ 机器人是否触发等待」配置（`empty_mention_waiting`）耦合——关闭配置后 `is_empty_mention` 判定不成立，空艾特虽然正常唤醒，却在 LLM 阶段被空消息跳过判定拦下（无文本、无媒体、无引用即跳过），完全无响应。两个开关配合冲突、逻辑混乱。

## 改造内容

### 删除特殊逻辑（`astrbot/builtin_stars/astrbot/main.py`）

- 整体删除 `handle_empty_mention` 处理器（priority=maxsize-1 的全事件监听）：空艾特直接 LLM 回复、60 秒等待窗口、下一条消息拼装重投递全部移除。
- 同步清理 import：`copy`、`SessionController` / `session_waiter`、`Comp`（`SessionWaiter` 仍被 `handle_session_control_agent` 使用，保留；`FILTERS` / `USER_SESSIONS` 同理）。

### 管线内空唤醒补提示词（`astrbot/core/pipeline/process_stage/method/agent_sub_stages/internal.py`）

- 空消息跳过判定处新增 `_fill_bare_wake_prompt`：判定为空唤醒时向 `event.message_str` 写入模块级常量 `_BARE_WAKE_PROMPT`（英文 system_reminder：用户 @ 了你但未输入内容，请结合对话上下文自然回应）后照常请求 LLM；判定不通过维持原跳过行为。
- `_is_bare_wake` 判定规则（要求 `event.is_wake` 为真）：
  - `At` 机器人 / `AtAll`（`AtAll` 继承自 `At`，其 `qq` 固定为 `"all"`）→ 命中空唤醒标记；
  - `Plain` 文本为空，或文本等于某个唤醒前缀（前缀已在唤醒阶段从 `message_str` 中移除、组件原文仍在，故按组件原文与 `wake_prefix` 列表比对）→ 命中标记；
  - 出现其他任何组件（`At` 别人、图片/语音/文件/引用/Json 等）→ 直接不算空唤醒。
- 提示词随 `message_str` 走：本次 LLM 请求与会话历史落库内容一致（与消息防抖合并的 system_reminder 做法对齐）；群聊上下文注入等 on_llm_request 机制天然生效。
- 空艾特消息不含文本/图片/Json 组件，不会被群聊上下文感知逻辑（`on_message` 的 `has_context_content` 判定）记入群聊历史，不污染后续注入。

### 配置清理（`astrbot/core/config/default.py`）

- 移除 `empty_mention_waiting`、`empty_mention_waiting_need_reply` 三处：默认值、schema 定义（hint 同步删除）、CONFIG_METADATA i18n 元数据（「只 @ 机器人是否触发等待」）。配置页 schema 驱动渲染，删项后自动消失；存量 data/config 配置文件中的残留键无害。

## 修改文件清单

1. `astrbot/builtin_stars/astrbot/main.py` — 删除 `handle_empty_mention` 与相关 import（保留 `SessionWaiter` / `FILTERS` / `USER_SESSIONS` 供会话控制代理使用）
2. `astrbot/core/pipeline/process_stage/method/agent_sub_stages/internal.py` — 空唤醒检测 `_is_bare_wake` / `_fill_bare_wake_prompt`、`_BARE_WAKE_PROMPT` 常量、import 增补 `At` / `AtAll` / `Plain`
3. `astrbot/core/config/default.py` — 配置项三处清理
4. `tests/test_bare_wake_prompt.py` — 新增回归测试
