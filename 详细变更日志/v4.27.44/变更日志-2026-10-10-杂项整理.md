## 2. dashboard/dist 预压缩产物不再纳入版本跟踪

`.gz` 是 dist 构建的预压缩副产物（每个 js/css/svg/html 各对应一份），共 73 个文件曾随仓库跟踪。问题：每次 WebUI 构建后文件哈希全部变化，diff 噪音巨大、仓库体积持续膨胀。

处理：

- `.gitignore` 新增 `dashboard/dist/**/*.gz`（覆盖 dist 根与 assets 子目录），另收录 `.idea/` 与 `.zcodeignore` 两个本地工具文件。
- 已跟踪的 73 个 `.gz` 以 `git rm --cached` 移出索引——磁盘文件全部保留，本地 WebUI 服务不受影响。

注意：以 git pull 方式更新 dist 的环境，今后不再收到 `.gz` 更新；新克隆环境需由构建流程生成 `.gz`，或直接使用未压缩资源。
