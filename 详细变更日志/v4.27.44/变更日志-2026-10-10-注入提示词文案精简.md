# [2026-10-10] 注入提示词文案精简

> 本文件为独立变更日志，记录群聊上下文块与空唤醒提示词的文案收紧，延续 2026-09-27「纯描述化」方向。

---

## 改动内容

原则不变：注入 LLM 的提示词一律英文、只陈述事实、不下指令——指令性表述（如「请自然回应」）会让模型机械服从，描述性表述让行为由上下文决定。本次把剩余两处冗长文案收紧：

### 群聊上下文块（group_chat_context.py）

- header：`You are currently in a group chat.` → `You are in a group chat.`
- footer：`Above is the group chat history before the current user message, arranged in chronological order. Below is the content of the current user message that immediately follows the chat history and needs to be processed.` → `Above is the group chat history in chronological order. Below is the current user message to be processed.`

结构不变：header 只留群聊声明与 `--- BEGIN CONTEXT ---` 边界，Above/Below 说明句在 footer，`--- END CONTEXT ---` 收尾。

### 空唤醒提示词（internal.py `_BARE_WAKE_PROMPT`）

- 旧：`The user woke you up with an @ mention or wake prefix but did not include any message content. Respond naturally based on the conversation context.`
- 新：`The user woke you up with an @ mention but did not include any content.`

去掉指令句「Respond naturally based on the conversation context.」；去掉唤醒前缀分支的枚举表述。判定逻辑（`_is_bare_wake`：仅 @ 自身、@ 全体、只发唤醒前缀均算空唤醒）与落库行为（提示词写入 message_str 随会话落库）均未变，仅文案收紧。
